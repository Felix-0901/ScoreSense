## 單元一｜先用直寫程式接起最短流程

目標：原圖 → 灰階 → 平滑 → 二值化。先不做傾斜、對比、存檔，不要同時除錯所有功能。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
smooth = cv2.GaussianBlur(gray, (3, 3), 0)
binary = cv2.adaptiveThreshold(smooth, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                               cv2.THRESH_BINARY, 31, 10)

cv2.imshow("Original", image)
cv2.imshow("Gray", gray)
cv2.imshow("Smooth", smooth)
cv2.imshow("Binary", binary)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

**檢查：**四個變數分別是哪個階段？`binary` 不是原圖，也不是灰階圖。調整 31 或 10 應影響二值化，而不是回頭改掉 `gray`。

這裡沒有任何新影像 API。看不懂某一步時，回到對應功能的小範例，單獨觀察。

## 單元二｜把一件事整理成函式

將「平滑 → 二值化」包成函式，讓設定從參數傳進來。

### 完整範例

```python
import cv2


def make_binary(gray, block_size=31, constant=10):
    smooth = cv2.GaussianBlur(gray, (3, 3), 0)
    binary = cv2.adaptiveThreshold(smooth, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                   cv2.THRESH_BINARY, block_size, constant)
    return binary


image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg")
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
result = make_binary(gray, block_size=31, constant=10)

cv2.imshow("Gray", gray)
cv2.imshow("Binary", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 寫法 | 在這個例子的角色 |
| --- | --- |
| `def make_binary(...)` | 定義一個完整工作，不是立即執行 |
| `gray` | 輸入的影像陣列 |
| `block_size=31`、`constant=10` | 可被指定值取代的預設參數 |
| `return binary` | 把新影像交回呼叫端 |
| `result = make_binary(...)` | 實際執行並接收回傳陣列 |

處理函式裡沒有 `waitKey()`。這樣多個步驟串接時不會每呼叫一次就被視窗卡住，顯示時機由外面的程式決定。

**練習：**呼叫兩次，分別用 C=5 與 C=15，比較回傳結果；確認輸入灰階保持相同。

## 單元三｜回傳多個階段

要讓使用者看懂變化，可以用字典回傳各階段，鍵是名稱，值是影像陣列。

### 完整範例

```python
import cv2


def process_steps(image):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    smooth = cv2.GaussianBlur(gray, (3, 3), 0)
    _, binary = cv2.threshold(smooth, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)
    return {"Original": image, "Gray": gray, "Smooth": smooth, "Binary": binary}


image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg")
stages = process_steps(image)
for title, stage in stages.items():
    print("目前階段：", title)
    cv2.imshow("Current stage", stage)
    cv2.waitKey(0)
cv2.destroyAllWindows()
```

`.items()` 每次提供一組「鍵、值」，可分別接成 `title`、`stage`。每按一次鍵，下一階段就顯示在同一個視窗，不必同時開很多視窗。

此例回傳的原圖仍是原陣列參照。處理函式沒有改動它；若之後想在其中一張畫框，先 `.copy()`。

## 單元四｜完整流程要怎麼選步驟？

下面是本章整合練習的資料流，不是規定所有 OMR 都要先這樣處理：

```text
讀取 test.jpg，保留來源
    ↓
過大才等比例縮小
    ↓
灰階
    ↓
Canny → 霍夫線段 → 估計方向
    ↓
沒有可用估計：保留灰階
有估計：產生旋轉候選，再檢查殘餘方向
    ↓
採用的灰階 → 可選 CLAHE → 灰階候選
                             ↓
                        溫和高斯濾波
                             ↓
                       二值化／邊緣預覽
```

預設不開 CLAHE，先保留不額外強化對比的基準；有需要再比較。侵蝕、膨脹、輪廓與透視轉換已在前章學過，但不因此變成每張圖必做的操作。

深色符號彼此相接、背景有線、紙張斜拍成梯形時，單靠近水平長線估角可能失敗。不能把「找到一致長線」當成「確認這些線就是五線譜」。

### 函式分工

| 函式 | 輸入 | 輸出 |
| --- | --- | --- |
| `read_image()` | 檔名 | BGR 陣列 |
| `resize_limit()` | 陣列、最大邊長 | 保持比例的工作圖 |
| `estimate_skew()` | 灰階 | 線方向或 None、原因 |
| `rotate_expand()` | 灰階、角度 | 擴大畫布後的灰階 |
| `preprocess_score()` | 檔名、設定 | 各階段影像與處理狀態 |

### 閱讀完整程式前

以下函式主要來自第 5～7 章。新使用的 `math.isfinite()` 用來拒絕無限大或 NaN 參數；`type(value) is int` 不把布林值當成整數設定。

`candidate_residual` 是旋轉候選的重新估計角度。候選不被採用時，這個值不是最終輸出角度。

先讀最下方如何呼叫 `preprocess_score("test.jpg")`，再沿著函式名稱往上找實作；不用一次背完整模組。

## 綜合實作｜完整模組與逐步視窗

### 一、建立 `lesson08_preprocess.py`

將下列完整程式存於專案根目錄。它不依賴任何 `lesson05_common.py` 等工具檔，讀不到來源就明確報錯，不會偷偷換成合成圖片。

它只產生記憶體中的處理結果與視窗，不會覆寫 `test.jpg`。

```python
from pathlib import Path
import math
import cv2
import numpy as np


def read_image(filename):
    raw = Path(filename).read_bytes()
    if not raw:
        raise ValueError("圖片檔案是空的")
    image = cv2.imdecode(np.frombuffer(raw, dtype=np.uint8), cv2.IMREAD_COLOR)
    if image is None:
        raise ValueError("檔案內容不是可解碼的圖片")
    return image


def resize_limit(image, max_side=1600):
    height, width = image.shape[:2]
    scale = min(1.0, max_side / max(height, width))
    if scale == 1.0:
        return image.copy()
    size = (max(1, round(width * scale)), max(1, round(height * scale)))
    return cv2.resize(image, size, interpolation=cv2.INTER_AREA)


def estimate_skew(gray):
    height, width = gray.shape
    smooth = cv2.GaussianBlur(gray, (3, 3), 0)
    edges = cv2.Canny(smooth, 50, 150, L2gradient=True)
    lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=40,
                            minLineLength=max(30, width // 3), maxLineGap=10)
    angles = []
    rows = []
    if lines is not None:
        for line in lines:
            x1, y1, x2, y2 = line[0]
            dx = float(x2 - x1)
            dy = float(y2 - y1)
            angle = np.degrees(np.arctan2(dy, dx))
            angle = (angle + 90) % 180 - 90
            if dx != 0 and abs(angle) <= 15:
                angles.append(float(angle))
                rows.append(float(y1) + (width / 2 - float(x1)) * dy / dx)

    estimated = None
    reason = "候選線段不足"
    if len(angles) >= 4:
        values = np.array(angles)
        median = float(np.median(values))
        consistent = np.abs(values - median) <= 2
        positions = sorted(np.array(rows)[consistent].tolist())
        row_count = 0
        last_row = None
        for row in positions:
            if last_row is None or row - last_row > 4:
                row_count += 1
                last_row = row
        if consistent.mean() >= 0.75 and consistent.sum() >= 4 and row_count >= 3:
            estimated = float(np.median(values[consistent]))
            reason = "取得方向相近且分布於不同高度的長線"
        else:
            reason = "線段方向或高度分布不足"
    return estimated, reason


def rotate_expand(gray, angle):
    if abs(angle) < 0.1:
        return gray.copy()
    height, width = gray.shape
    center = ((width - 1) / 2, (height - 1) / 2)
    matrix = cv2.getRotationMatrix2D(center, angle, 1.0)
    cosine = abs(matrix[0, 0])
    sine = abs(matrix[0, 1])
    new_width = int(np.ceil(width * cosine + height * sine))
    new_height = int(np.ceil(height * cosine + width * sine))
    matrix[0, 2] += (new_width - 1) / 2 - center[0]
    matrix[1, 2] += (new_height - 1) / 2 - center[1]
    rotated = cv2.warpAffine(gray, matrix, (new_width, new_height),
                             flags=cv2.INTER_LINEAR,
                             borderMode=cv2.BORDER_CONSTANT, borderValue=255)
    return rotated


def preprocess_score(filename, use_clahe=False, block_size=31, constant=10):
    if type(use_clahe) is not bool:
        raise TypeError("use_clahe 必須是布林值")
    if type(block_size) is not int or block_size < 3 or block_size % 2 == 0:
        raise ValueError("block_size 必須是大於 1 的奇數整數")
    if isinstance(constant, bool) or not isinstance(constant, (int, float)):
        raise TypeError("constant 必須是數值")
    if not math.isfinite(constant):
        raise ValueError("constant 必須是有限數值")

    original = read_image(filename)
    working = resize_limit(original)
    gray = cv2.cvtColor(working, cv2.COLOR_BGR2GRAY)
    if min(gray.shape) < max(32, block_size):
        raise ValueError("圖片太小，請調整素材或門檻區域設定")

    estimated, reason = estimate_skew(gray)
    corrected = gray.copy()
    applied = 0.0
    residual = None
    status = "no_estimate"
    if estimated is not None:
        if abs(estimated) < 0.1:
            status = "near_horizontal"
            residual = estimated
        else:
            candidate = rotate_expand(gray, estimated)
            residual, _ = estimate_skew(candidate)
            if residual is not None and abs(residual) <= 1.0:
                corrected = candidate
                applied = estimated
                status = "rotated"
            else:
                status = "rejected_candidate"

    preprocessed = corrected.copy()
    if use_clahe:
        clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
        preprocessed = clahe.apply(corrected)
    smooth = cv2.GaussianBlur(preprocessed, (3, 3), 0)
    binary = cv2.adaptiveThreshold(smooth, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                   cv2.THRESH_BINARY, block_size, constant)
    edges = cv2.Canny(smooth, 50, 150, L2gradient=True)

    return {
        "stages": {
            "Original": original,
            "Working size": working,
            "Gray": gray,
            "Corrected gray": corrected,
            "Preprocessed candidate": preprocessed,
            "Smoothed for preview": smooth,
            "Binary preview": binary,
            "Edges preview": edges,
        },
        "estimated_angle": estimated,
        "applied_rotation": applied,
        "candidate_residual": residual,
        "status": status,
        "reason": reason,
    }


if __name__ == "__main__":
    result = preprocess_score("test.jpg")
    print("狀態：", result["status"])
    print("估計、採用角度：", result["estimated_angle"], result["applied_rotation"])
    print("原因：", result["reason"])
    for title, stage in result["stages"].items():
        print("目前階段：", title, stage.shape)
        cv2.namedWindow("Current stage", cv2.WINDOW_NORMAL)
        cv2.resizeWindow("Current stage", 900, 650)
        cv2.imshow("Current stage", stage)
        cv2.waitKey(0)
    cv2.destroyAllWindows()
```

### 二、執行與觀察

執行 `python lesson08_preprocess.py`。每按一次鍵，依序查看原圖、工作尺寸、灰階、校正後灰階、候選圖與預覽。請同時看終端機印出的階段與尺寸。

`if __name__ == "__main__":` 是 A 章的主程式入口：直接執行會進行示範，被其他程式匯入時不會自動開視窗。

| 狀態 | 意義 |
| --- | --- |
| `no_estimate` | 沒有足夠一致線段，保留灰階，不宣稱原圖水平 |
| `near_horizontal` | 有估計且已接近水平，不必多做一次插值 |
| `rotated` | 候選重新估計後殘餘角度在本例門檻內，採用旋轉 |
| `rejected_candidate` | 候選無法重新估計或殘餘角度偏大，退回原灰階 |

這些只記錄方向處理狀態，並不是音符辨識正確率。再次估角使用同一方法，也不是獨立的音樂真值驗證。

### 三、哪些步驟不送進 OMR？

本章保留 `Preprocessed candidate` 作為可比較的灰階候選。高斯平滑、二值化和邊緣圖是預覽支線，不能不分用途全部改成 OMR 的輸入。

`IMREAD_COLOR` 取得三通道，不是完整的透明背景處理。這個整合範例以一般不透明 JPEG／PNG 為主；透明 PNG 的白底合成見第 5 章，16 位元、多頁與彎曲書頁需另外設計。

本章是獨立教學模組，未改動 `app/services/` 的執行程式。後續接入專案前仍要核對參數、回傳介面與 OMR 實驗，不能因為函式也叫 `preprocess_score` 就直接互相替換。

## 單元六｜另存結果與設定

先觀察滿意，再保存結果。下面使用第 3 章的 `Path`／JSON 與第 5 章的圖片編碼。建立 `lesson08_save.py`。

輸出使用新資料夾 `output/lesson08_run01`；已存在時停止，請換新的編號。程式不清除舊資料，也不把來源當輸出。

```python
import json
from pathlib import Path
import cv2
from lesson08_preprocess import preprocess_score

result = preprocess_score("test.jpg", use_clahe=False, block_size=31, constant=10)
output = Path("output") / "lesson08_run01"
output.mkdir(parents=True, exist_ok=False)

for filename, stage_name in [("preprocessed.png", "Preprocessed candidate"),
                              ("binary_preview.png", "Binary preview")]:
    ok, encoded = cv2.imencode(".png", result["stages"][stage_name])
    if not ok:
        raise OSError("PNG 編碼失敗")
    with (output / filename).open("xb") as file:
        file.write(encoded.tobytes())

report = {
    "source": "test.jpg",
    "use_clahe": False,
    "block_size": 31,
    "constant": 10,
    "estimated_angle": result["estimated_angle"],
    "applied_rotation": result["applied_rotation"],
    "candidate_residual": result["candidate_residual"],
    "status": result["status"],
    "reason": result["reason"],
}
with (output / "report.json").open("x", encoding="utf-8") as file:
    json.dump(report, file, ensure_ascii=False, indent=2, allow_nan=False)
print("已儲存：", output)
cv2.imshow("Saved candidate", result["stages"]["Preprocessed candidate"])
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`imencode()` 回傳成功旗標與編碼後位元組陣列；`.tobytes()` 交成 Python 位元組，用 `"xb"` 寫入新檔，避免原圖路徑與中文路徑的編碼混在一起。

報告只存參數與純資料，沒有把 NumPy 影像陣列直接交給 `json.dump()`。修改處理設定時，也要同步報告中的設定值。

若寫入途中失敗，資料夾可能已有部分檔案；這段沒有完整的交易回復機制，不應只用資料夾存在就判定成功。

## 單元七｜驗證與修改方向

### 先列出情況，再執行

| 測試素材／操作 | 應檢查 |
| --- | --- |
| 清楚水平五線 | 是否近水平，有沒有不必要旋轉 |
| 已知 +7／−7 度副本 | 符號是否正確，校正後線是否水平 |
| 空白圖、沒有長線 | 是否回報沒有估計，而非假裝校正成功 |
| 有頁框或桌面線 | 是否誤把背景當方向依據 |
| 少了 `test.jpg` | 是否停止並指出讀檔問題 |
| `block_size=30` | 是否在影像 API 前拒絕偶數 |
| 重跑存檔範例 | 是否保留舊結果而要求換新目錄 |
