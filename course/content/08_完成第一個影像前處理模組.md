# 第 8 章｜完成第一個影像前處理模組

前面已經分別完成陣列操作、圖片讀寫、色彩轉換、二值化、濾波、形態學、邊緣與方向估計。現在把適合一起使用的步驟整理成函式，讓一張圖片能有明確的輸入、輸出與處理紀錄。

整合不代表把所有方法都套一遍。它需要先決定哪些步驟是必要的，哪些只是實驗分支，哪些情況應停止或要求檢查。

## 學習目標

- 畫出資料流，定義每個階段的輸入與輸出。
- 使用 `dataclass` 表達設定與結果。
- 建立完整 `preprocess_score()`，保留來源並記錄參數。
- 分辨沒有估計、原本水平、已旋轉與未採用旋轉。
- 以已知角度、空白圖、損壞檔案與不合法參數驗證流程。

## 單元一｜從單一方法到處理流程

### 1-1｜先決定輸出給誰

同一張圖片可以產生不同用途的結果：灰階候選圖保留亮暗資訊，二值圖用來觀察分割，邊緣圖用來檢查結構。它們不能不分用途地互相替代。

本章保留：

| 輸出 | 用途 |
| --- | --- |
| `original_decoded.png` | 解碼並統一通道後的來源像素副本 |
| `gray_before.png` | 縮放後、校正前的灰階基準 |
| `preprocessed.png` | 幾何校正後的灰階候選，可選擇加入 CLAHE |
| `preview_input.png` | 二值化前使用的灰階或平滑圖 |
| `binary_preview.png` | 自適應二值化的觀察結果 |
| `edges_preview.png` | 邊緣診斷圖 |
| `report.json` | 設定、版本、尺寸、角度與採用狀態 |

灰階候選不保證比原圖更適合 OMR；後續需要比較原始輸入與候選輸入的實際辨識結果。

### 1-2｜先用小圖接起最短流程

### 範例：灰階、平滑與二值化

```python
import cv2
import numpy as np

image = np.full((80, 120, 3), 230, dtype=np.uint8)
image[25:55, 30:90] = (20, 20, 20)
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
smooth = cv2.GaussianBlur(gray, (3, 3), sigmaX=0)
binary = cv2.adaptiveThreshold(smooth, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                               cv2.THRESH_BINARY, 31, 10)
print("灰階：", gray.shape, gray.dtype)
print("二值圖：", binary.shape, binary.dtype, np.unique(binary))
print("黑色像素數：", np.count_nonzero(binary == 0))
```

這段程式只確認資料能串接，並不保證二值圖會把矩形內部全部塗黑。局部門檻在大面積均勻暗區也可能把中心判成白色，因此仍要檢查方法是否符合目的。

## 單元二｜設定、結果與 `dataclass`

函式參數太多時，可以用資料類別把設定集中；回傳多個值時，也可以用欄位名稱表達意義，避免記住 `result[0]`、`result[1]` 的順序。

### 範例：有名字的設定與結果

```python
from dataclasses import asdict, dataclass


@dataclass(frozen=True)
class DemoConfig:
    block_size: int = 31
    constant: float = 10.0


@dataclass(frozen=True)
class DemoResult:
    applied_angle: float
    status: str


config = DemoConfig(constant=5.0)
result = DemoResult(applied_angle=0.0, status="skipped_no_estimate")
print(config.block_size)
print(asdict(config))
print(result.applied_angle, result.status)
```

`@dataclass` 依欄位產生初始化等方法；`frozen=True` 限制欄位重新賦值，但不等於所有巢狀物件都變成不可修改。型別提示也不會自動驗證輸入，所以正式處理前仍要檢查設定。

## 單元三｜用驗證避免錯誤傳到下一步

### 3-1｜驗證輸入資料與參數

讀圖失敗時就停止，不要等 `cvtColor()` 報錯才猜原因。圖片過小、門檻區域為偶數、參數不是有限數值，都應在呼叫相關影像函式前處理。

### 範例：門檻參數檢查

```python
def validate_block_size(value):
    if type(value) is not int or value < 3 or value % 2 == 0:
        raise ValueError("block_size 必須是大於 1 的奇數整數")
    return value


for value in [31, 30, 1, True, "31"]:
    try:
        print("可使用：", validate_block_size(value))
    except ValueError as error:
        print(f"拒絕 {value!r}：{error}")
```

這裡使用 `type(value) is int`，是為了不把布林值當成整數設定。不要遇到偶數就默默加一，因為報告中的參數可能與真正使用的不同。

### 3-2｜估計角度與採用角度分開

`estimated_angle=None` 表示沒有採用的估計；`applied_rotation=0.0` 表示沒有真的轉動。若圖片本來就接近水平，也可能不必插值。

旋轉候選圖後再量測。如果方向不穩定或無法重新量測，本章回到旋轉前灰階，記錄 `skipped_unstable_correction`，而不是將「有產生檔案」視為校正成功。

## 單元四｜規劃模組的資料流

```text
來源檔案
    ↓
讀取並解碼；確認深度與通道
    ↓
過寬時等比例縮小
    ↓
灰階基準
    ↓
估計方向 → 無法估計：保留並記錄
    ↓
產生旋轉候選 → 再量測不穩：不採用
    ↓
採用的灰階圖
    ├──→ 可選 CLAHE → preprocessed.png
    │                        ↓
    │                  可選溫和濾波
    │                        ↓
    │               二值化預覽與邊緣預覽
    └──→ 報告：設定、尺寸、狀態、版本
```

本章不預設對照片套用開運算或閉運算，也不預設移除五線。這些會改變細小結構，應先在第 6 章的獨立比較分支確認必要性。

平移、翻轉與透視轉換也不是固定必經步驟；只有輸入確實需要，而且已知道轉換條件時才加入。

### 二、完整模組：`image_preprocessor.py`

下列內容包括設定、驗證、讀寫、縮放、估角、旋轉與流程，不需從其他章節補函式。

```python
from dataclasses import asdict, dataclass
from pathlib import Path
from tempfile import mkdtemp
import json
import math
import sys
import cv2
import numpy as np


@dataclass(frozen=True)
class PreprocessConfig:
    max_width: int = 1800
    use_clahe: bool = False
    clip_limit: float = 2.0
    blur_size: int = 3
    block_size: int = 31
    constant: float = 10.0
    max_skew: float = 15.0


@dataclass(frozen=True)
class PreprocessResult:
    enhanced_path: Path
    binary_path: Path
    rotation_degrees: float
    report_path: Path
    status: str
    needs_review: bool


def validate_config(config):
    if type(config.max_width) is not int or config.max_width < 32:
        raise ValueError("max_width 必須是至少 32 的整數")
    if type(config.blur_size) is not int or config.blur_size not in (1, 3, 5):
        raise ValueError("blur_size 只接受 1、3、5；1 表示不模糊")
    if type(config.block_size) is not int or config.block_size < 3 or config.block_size % 2 == 0:
        raise ValueError("block_size 必須是大於 1 的奇數")
    if type(config.use_clahe) is not bool:
        raise TypeError("use_clahe 必須是布林值")
    for name in ("clip_limit", "constant", "max_skew"):
        value = getattr(config, name)
        if isinstance(value, bool) or not isinstance(value, (int, float)) or not math.isfinite(value):
            raise ValueError(f"{name} 必須是有限數值")
    if config.clip_limit <= 0 or not 0 < config.max_skew <= 15:
        raise ValueError("clip_limit 必須大於 0，max_skew 必須介於 0 與 15 度之間")


def read_image(path):
    raw = Path(path).read_bytes()
    if not raw:
        raise ValueError("來源檔案是空的")
    image = cv2.imdecode(np.frombuffer(raw, dtype=np.uint8), cv2.IMREAD_UNCHANGED)
    if image is None:
        raise ValueError("來源不是可解碼的圖片")
    if image.dtype != np.uint8:
        raise ValueError("本模組只接受 8 位元影像，其他深度需要先決定轉換規則")
    if image.ndim == 2:
        return cv2.cvtColor(image, cv2.COLOR_GRAY2BGR)
    if image.ndim == 3 and image.shape[2] == 3:
        return image
    if image.ndim == 3 and image.shape[2] == 4:
        alpha = image[:, :, 3:4].astype(np.float32) / 255.0
        result = image[:, :, :3].astype(np.float32) * alpha + 255 * (1 - alpha)
        return np.rint(result).clip(0, 255).astype(np.uint8)
    raise ValueError("不支援的影像通道排列")


def write_png(path, image):
    path = Path(path)
    if path.suffix.lower() != ".png":
        raise ValueError("輸出路徑必須使用 .png")
    if image.dtype != np.uint8 or image.size == 0:
        raise ValueError("需要非空 uint8 影像")
    ok, buffer = cv2.imencode(".png", np.ascontiguousarray(image))
    if not ok:
        raise ValueError("PNG 編碼失敗")
    with path.open("xb") as file:
        file.write(buffer.tobytes())


def resize_limit(image, max_width):
    h, w = image.shape[:2]
    if w <= max_width:
        return image.copy()
    new_h = max(1, round(h * max_width / w))
    return cv2.resize(image, (max_width, new_h), interpolation=cv2.INTER_AREA)


def rotate_expand(image, degrees):
    if image.dtype != np.uint8 or image.ndim not in (2, 3) or image.size == 0:
        raise ValueError("需要非空的 uint8 灰階圖或三通道圖")
    if image.ndim == 3 and image.shape[2] != 3:
        raise ValueError("彩圖需要三個通道")
    if not np.isfinite(degrees):
        raise ValueError("旋轉角度必須是有限數值")
    if abs(degrees) < 1e-9:
        return image.copy()
    h, w = image.shape[:2]
    center = ((w - 1) / 2.0, (h - 1) / 2.0)
    matrix = cv2.getRotationMatrix2D(center, float(degrees), 1.0)
    cosine, sine = abs(matrix[0, 0]), abs(matrix[0, 1])
    new_w = int(np.ceil(w * cosine + h * sine))
    new_h = int(np.ceil(h * cosine + w * sine))
    matrix[0, 2] += (new_w - 1) / 2.0 - center[0]
    matrix[1, 2] += (new_h - 1) / 2.0 - center[1]
    border = 255 if image.ndim == 2 else (255, 255, 255)
    return cv2.warpAffine(image, matrix, (new_w, new_h),
                          flags=cv2.INTER_LINEAR,
                          borderMode=cv2.BORDER_CONSTANT, borderValue=border)


def estimate_hough(gray, max_angle=15.0):
    if gray.ndim != 2 or gray.dtype != np.uint8 or gray.size == 0:
        raise ValueError("需要非空 uint8 灰階圖")
    h, w = gray.shape
    if min(h, w) < 32:
        return None, {"reason": "圖片太小", "segments": 0}
    smooth = cv2.GaussianBlur(gray, (3, 3), sigmaX=0)
    edges = cv2.Canny(smooth, 50, 150, L2gradient=True)
    lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=40,
                            minLineLength=max(30, round(w * 0.35)), maxLineGap=10)
    if lines is None:
        return None, {"reason": "找不到長線段", "segments": 0}
    angles, positions = [], []
    for x1, y1, x2, y2 in lines[:, 0, :]:
        dx, dy = float(x2 - x1), float(y2 - y1)
        angle = (float(np.degrees(np.arctan2(dy, dx))) + 90) % 180 - 90
        if dx == 0 or abs(angle) > max_angle:
            continue
        angles.append(angle)
        positions.append(float(y1) + ((w - 1) / 2 - float(x1)) * dy / dx)
    if len(angles) < 4:
        return None, {"reason": "候選長線段不足", "segments": len(angles)}
    values = np.array(angles)
    median = float(np.median(values))
    inliers = np.abs(values - median) <= 2.0
    ratio = float(inliers.mean())
    if ratio < 0.75 or np.count_nonzero(inliers) < 4:
        return None, {"reason": "線段方向不一致", "segments": len(angles)}
    rows = sorted(np.array(positions)[inliers].tolist())
    groups = 1
    anchor = rows[0]
    for row in rows[1:]:
        if row - anchor > 4.0:
            groups += 1
            anchor = row
    if groups < 3:
        return None, {"reason": "不同高度的線段不足", "segments": len(angles)}
    return float(np.median(values[inliers])), {
        "reason": "取得多條方向一致的長線段", "segments": len(angles),
        "inlier_ratio": ratio, "row_groups": groups,
    }


def preprocess_score(input_path, output_dir, config=None):
    config = PreprocessConfig() if config is None else config
    validate_config(config)
    input_path = Path(input_path)
    image = read_image(input_path)
    resized = resize_limit(image, config.max_width)
    gray = cv2.cvtColor(resized, cv2.COLOR_BGR2GRAY)
    if min(gray.shape) < max(32, config.block_size):
        raise ValueError("縮放後圖片太小，無法使用本次方向與門檻設定")

    angle, angle_detail = estimate_hough(gray, config.max_skew)
    applied = 0.0
    corrected = gray.copy()
    candidate_residual = None
    needs_review = angle is None
    if angle is None:
        status = "skipped_no_estimate"
    elif abs(angle) < 0.1:
        status = "already_near_horizontal"
        candidate_residual = angle
    else:
        candidate = rotate_expand(gray, angle)
        candidate_residual, _ = estimate_hough(candidate, config.max_skew)
        if candidate_residual is None or abs(candidate_residual) > 1.0:
            status = "skipped_unstable_correction"
            needs_review = True
        else:
            corrected = candidate
            applied = angle
            status = "rotated"

    if config.use_clahe:
        clahe = cv2.createCLAHE(clipLimit=config.clip_limit, tileGridSize=(8, 8))
        enhanced = clahe.apply(corrected)
    else:
        enhanced = corrected.copy()
    preview_input = enhanced.copy()
    if config.blur_size > 1:
        preview_input = cv2.GaussianBlur(enhanced, (config.blur_size, config.blur_size), sigmaX=0)
    binary = cv2.adaptiveThreshold(preview_input, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                   cv2.THRESH_BINARY, config.block_size, config.constant)
    edges = cv2.Canny(preview_input, 50, 150, L2gradient=True)

    output_dir = Path(output_dir)
    output_dir.mkdir(parents=True, exist_ok=True)
    run = Path(mkdtemp(prefix="run_", dir=str(output_dir)))
    outputs = {
        "original_decoded": image,
        "gray_before": gray,
        "preprocessed": enhanced,
        "preview_input": preview_input,
        "binary_preview": binary,
        "edges_preview": edges,
    }
    for name, result in outputs.items():
        write_png(run / f"{name}.png", result)
    report = {
        "source_name": input_path.name,
        "input_shape": list(image.shape),
        "working_shape": list(gray.shape),
        "output_shape": list(enhanced.shape),
        "config": asdict(config),
        "estimated_angle": angle,
        "applied_rotation": applied,
        "candidate_residual_angle": candidate_residual,
        "status": status,
        "angle_detail": angle_detail,
        "needs_review": needs_review,
        "foreground_ratio_preview": float(np.mean(binary == 0)),
        "versions": {"python": sys.version.split()[0], "opencv": cv2.__version__,
                     "numpy": np.__version__},
    }
    report_path = run / "report.json"
    with report_path.open("x", encoding="utf-8") as file:
        file.write(json.dumps(report, ensure_ascii=False, indent=2, allow_nan=False) + "\n")
    return PreprocessResult(
        enhanced_path=run / "preprocessed.png",
        binary_path=run / "binary_preview.png",
        rotation_degrees=applied,
        report_path=report_path,
        status=status,
        needs_review=needs_review,
    )
```

### 三、完整執行程式：`lesson08_run.py`

不傳入路徑時，程式自行建立已知 `+7` 度傾斜的素材。傳入路徑時只讀取該檔案，讀不到就回報錯誤，不會偷偷換成示範圖。

```python
from pathlib import Path
from tempfile import mkdtemp
import sys
import cv2
import numpy as np
from image_preprocessor import PreprocessConfig, preprocess_score, rotate_expand, write_png

BASE_DIR = Path(__file__).resolve().parent


def make_demo():
    image = np.full((280, 640), 255, dtype=np.uint8)
    for top in (75, 175):
        for index in range(5):
            y = top + index * 10
            cv2.line(image, (45, y), (595, y), 30, 1)
        for x in (140, 260, 380, 500):
            cv2.ellipse(image, (x, top + 20), (7, 5), -20, 0, 360, 20, -1)
            cv2.line(image, (x + 6, top + 20), (x + 6, top - 5), 20, 2)
    return rotate_expand(image, 7.0)


def main():
    if len(sys.argv) > 1:
        source = Path(sys.argv[1]).expanduser().resolve()
    else:
        root = BASE_DIR / "output" / "lesson08_demo_inputs"
        root.mkdir(parents=True, exist_ok=True)
        source_dir = Path(mkdtemp(prefix="demo_", dir=str(root)))
        source = source_dir / "generated_skewed.png"
        write_png(source, make_demo())

    config = PreprocessConfig(use_clahe=False, blur_size=3, block_size=31, constant=10)
    result = preprocess_score(source, BASE_DIR / "output" / "lesson08", config)
    print("狀態：", result.status)
    print("採用旋轉：", result.rotation_degrees)
    print("需檢查方向：", result.needs_review)
    print("灰階候選：", result.enhanced_path)
    print("二值預覽：", result.binary_path)
    print("處理紀錄：", result.report_path)


if __name__ == "__main__":
    main()
```

執行 `python lesson08_run.py`，或 `python lesson08_run.py "照片路徑.png"`。每次結果位於不同 `run_...` 目錄，不覆蓋原圖或前一次報告。

### 四、逐段追蹤設計

**讀取與通道統一。**灰階轉成三通道，BGRA 則合成白底。本例只接受 `uint8`；16 位元圖需要先決定灰階映射，不能直接截斷。

`IMREAD_UNCHANGED` 不會依 EXIF 方向資訊自動旋轉。帶有方向標籤的手機照片，需要先檢查實際像素朝向；此模組只做輕微傾斜，不自動猜 90 度方向。

**縮放。**只有超過 `max_width` 才縮小，不自動放大。保留輸入與工作尺寸，因為後面以像素為單位的核與線段長度會受影響。

**方向決策。**分開記錄估計值、實際採用旋轉量、候選圖殘餘方向與狀態。`candidate_residual_angle` 只描述候選評估，不一定是最後輸出圖的角度，尤其是在拒絕候選時。

**灰階與預覽分開。**`blur_size` 作用在二值化預覽的輸入，不會偷偷改動 `preprocessed.png`。`use_clahe=False` 保留一個不加對比強化的基準。

**輸出與失敗。**先完成影像運算，再建立新目錄。每個檔案只以新檔模式寫入；若途中磁碟寫入失敗，程式會提出例外，目錄可能留下部分輸出。這不是一個具有完整交易回復的儲存系統，不能只看目錄存在就判定成功。

### 五、預期結果

對內建 `+7` 度素材，採用旋轉應接近 `-7` 度，狀態通常是 `rotated`。二值預覽與處理後灰階尺寸應一致，二值圖只有 `0` 與 `255`。

`needs_review` 在本例只追蹤**方向估計／旋轉採用**是否需要檢查；`false` 不是影像品質、內容完整性或 OMR 可用性的保證。

## 單元五｜比較設定，而不是找一組萬用參數

完成前面的兩支程式後，可以用同一張來源圖產生不同設定的結果。

### 範例：保留基準，再比較 CLAHE

存成 **`lesson08_compare.py`**。執行時必須提供來源圖片路徑。

```python
from pathlib import Path
import sys
from image_preprocessor import PreprocessConfig, preprocess_score


def main():
    if len(sys.argv) != 2:
        raise SystemExit("用法：python lesson08_compare.py 圖片路徑")
    source = Path(sys.argv[1]).expanduser().resolve()
    output = Path(__file__).resolve().parent / "output" / "lesson08_compare"
    for name, config in [
        ("baseline", PreprocessConfig(use_clahe=False)),
        ("clahe", PreprocessConfig(use_clahe=True, clip_limit=2.0)),
    ]:
        result = preprocess_score(source, output / name, config)
        print(name, result.enhanced_path, result.status)


if __name__ == "__main__":
    main()
```

## 單元六｜寫一支能重跑的檢查程式

### 6-1｜先定義能檢查的結果

| 輸入或設定 | 檢查重點 |
| --- | --- |
| 已知 `+7` 與 `-7` 度 | 旋轉符號正確、殘餘方向接近水平 |
| 水平圖 | 不應為了處理而多做一次插值 |
| 空白圖或只有一條長線 | 保留，標示沒有足夠估計 |
| 路徑不存在、空檔、非圖片 | 提出明確錯誤 |
| 偶數 `block_size` | 在二值化前拒絕 |
| 透明 PNG | 檢查白底合成與通道 |
| 同一來源重跑 | 新結果使用不同目錄，原檔位元組不變 |

### 範例：自動檢查核心行為

存成 **`lesson08_check.py`**，與完整模組放在同一資料夾。這支程式只在暫存目錄建立自製資料，不需要修改自己的照片。

```python
from pathlib import Path
from tempfile import TemporaryDirectory
import json
import cv2
import numpy as np
from image_preprocessor import (
    PreprocessConfig, preprocess_score, rotate_expand, write_png, read_image,
)


def horizontal_lines():
    image = np.full((280, 640), 255, dtype=np.uint8)
    for top in (75, 175):
        for index in range(5):
            y = top + index * 10
            cv2.line(image, (45, y), (595, y), 20, 1)
    return image


def main():
    with TemporaryDirectory(prefix="image_lesson_check_") as temporary:
        root = Path(temporary)
        for known in (-7.0, 0.0, 7.0):
            source = root / f"angle_{known}.png"
            write_png(source, rotate_expand(horizontal_lines(), known))
            before = source.read_bytes()
            result = preprocess_score(source, root / "results")
            report = json.loads(result.report_path.read_text(encoding="utf-8"))
            assert source.read_bytes() == before
            assert not result.needs_review
            assert abs(result.rotation_degrees + known) < 1.0
            binary = cv2.cvtColor(read_image(result.binary_path), cv2.COLOR_BGR2GRAY)
            assert set(np.unique(binary).tolist()).issubset({0, 255})
            assert report["config"]["block_size"] == 31

        blank = root / "blank.png"
        write_png(blank, np.full((280, 640), 255, dtype=np.uint8))
        first = preprocess_score(blank, root / "results")
        second = preprocess_score(blank, root / "results")
        assert first.status == "skipped_no_estimate"
        assert first.needs_review
        assert first.enhanced_path.parent != second.enhanced_path.parent

        try:
            preprocess_score(blank, root / "results", PreprocessConfig(block_size=30))
        except ValueError:
            pass
        else:
            raise AssertionError("偶數 block_size 應被拒絕")

        broken = root / "not_an_image.png"
        broken.write_bytes(b"not image data")
        try:
            preprocess_score(broken, root / "results")
        except ValueError:
            pass
        else:
            raise AssertionError("非圖片內容應被拒絕")
    print("本次列出的核心檢查通過")


if __name__ == "__main__":
    main()
```

執行 `python lesson08_check.py`。`assert` 用於這裡的測試，不取代正式函式的輸入驗證；Python 的最佳化模式可能停用 assertion，因此不要用 `python -O` 執行這支檢查。

測試通過只代表這些已列出的條件通過，不包含所有真實照片、不同套件版本、EXIF 方向或 OMR 辨識品質。

## 綜合延伸｜從實驗到下一步

先選三種輸入：乾淨掃描、輕微傾斜、光照不均。每張都保留來源，固定尺寸與其他設定，只比較一個改動。

### 引導思考

**圖片是否真的需要旋轉？**先看採用狀態與線段位置。沒有可靠角度時，人工確認比擴大允許範圍更合理。

**灰階候選是否保留小結構？**比較五線、附點與符桿。預覽變得更黑白分明，不代表符號資訊增加。

**如何與後續辨識連接？**以 `result.enhanced_path` 取得候選路徑，同時保留原始輸入作對照；`binary_path` 先用於觀察。不要在本階段宣稱已經讀出音高。

**如何加入新方法？**先在第 6 或第 7 章的獨立範例驗證，再新增有名稱的設定、結果與測試。說明該方法何時啟用、何時跳過，以及可能損失什麼。

### 修改練習

加入每個階段的耗時紀錄，但不要把耗時當作品質。再加入一個「只產生診斷圖、不自動旋轉」的選項。最後將前後圖的尺寸與縮放比例寫入摘要，說明為什麼座標不能跨不同大小的圖直接沿用。
