# 第 6 章｜灰階、對比、二值化與雜訊

樂譜辨識需要看清楚「黑色符號」與「白色背景」。但手機拍攝可能有陰影、亮度不均、模糊與雜訊。

這一章開始回答：**怎麼把一張不理想的樂譜照片，整理成比較適合辨識的輸入？**

## 學習目標

- 理解灰階化在樂譜處理中的角色。
- 比較全域 Threshold、Otsu 與 Adaptive Threshold。
- 使用 CLAHE 改善局部對比。
- 使用 Gaussian Blur 做溫和降噪。
- 用同一張圖比較不同處理方法，而不是只背函式。

## 單元四｜Otsu：讓程式估門檻

```python
threshold_value, binary = cv2.threshold(
    gray,
    0,
    255,
    cv2.THRESH_BINARY + cv2.THRESH_OTSU,
)

print("Otsu threshold:", threshold_value)
```

Otsu 仍然是一個全圖門檻，只是門檻值由資料估計。

因此如果整張圖片亮度差異非常大，仍可能不完美。

---

## 單元五｜Adaptive Threshold

```python
adaptive = cv2.adaptiveThreshold(
    gray,
    255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY,
    31,
    15,
)
```

它不是只使用一個全圖門檻，而會看鄰近區域。

兩個重要參數：

```text
31 → 區域大小，必須是奇數
15 → 從局部估計值再調整多少
```

不要直接背「31、15最好」。請把它們當成目前的實驗設定。

### 修改練習

比較：

```text
blockSize = 15, 31, 51
C = 5, 15, 25
```

每次只改一個條件。

---

## 單元六｜CLAHE：改善局部對比

```python
clahe = cv2.createCLAHE(
    clipLimit=2.0,
    tileGridSize=(8, 8),
)

enhanced = clahe.apply(gray)
```

CLAHE 把圖片分成小區域調整對比，並限制過度放大。

對拍照樂譜來說，它可能讓陰影區的線條更容易看清楚。

但如果 `clipLimit` 過大，也可能把紙張紋理與雜訊一起強化。

---

## 單元七｜Gaussian Blur：為什麼模糊反而有用？

```python
denoised = cv2.GaussianBlur(enhanced, (3, 3), 0)
```

目的不是把樂譜弄糊，而是壓低小範圍雜訊，讓二值化比較穩定。

如果 kernel 太大，細五線譜與小音符也可能被破壞。

比較：

```text
(3, 3)
(5, 5)
(9, 9)
```

## 綜合實作｜做出本專題的前處理前半段

```python
import cv2

image = cv2.imread("materials/score_shadow.png")
if image is None:
    raise FileNotFoundError("找不到圖片")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
enhanced = clahe.apply(gray)

denoised = cv2.GaussianBlur(enhanced, (3, 3), 0)

binary = cv2.adaptiveThreshold(
    denoised,
    255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY,
    31,
    15,
)

cv2.imwrite("output/06_enhanced.png", enhanced)
cv2.imwrite("output/06_binary.png", binary)
```
