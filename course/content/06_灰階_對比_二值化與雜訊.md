# 第 6 章｜灰階、對比、二值化與雜訊

圖片太暗、光照不均、出現雜點，是不同問題。本章逐一觀察調整亮度、對比、濾波、二值化與形態學的效果，不把所有方法當成固定必經流程。

繼續使用 **Python 3.11**，並從專案根目錄讀取 `test.jpg`。每段程式獨立執行，直接顯示原灰階圖與結果；不需要建立工具檔。`imread()`、`cvtColor()`、`imshow()`、`waitKey()`、`destroyAllWindows()` 已在第 4、5 章介紹。

## 學習目標

- 看懂亮度、對比與直方圖。
- 比較固定門檻、Otsu 與自適應門檻。
- 分辨椒鹽／高斯雜訊，以及不同濾波方法。
- 理解侵蝕、膨脹、開運算與閉運算如何改變前景。
- 以相同輸入比較方法，指出改善與資訊損失。

## 單元一｜灰階與亮度調整

灰階是 0～255 的亮暗，不是只剩黑白。增加亮度是把每個灰階加上偏移值，過亮的部分會被截成 255。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

bright = np.clip(gray.astype(np.float32) + 40, 0, 255).astype(np.uint8)
dark = np.clip(gray.astype(np.float32) - 40, 0, 255).astype(np.uint8)

cv2.imshow("Gray", gray)
cv2.imshow("Bright", bright)
cv2.imshow("Dark", dark)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`np.clip(array, 0, 255)` 和前章的 `array.clip(0, 255)` 用途相同。先以浮點數計算，才不會因為 `uint8` 回繞而產生錯誤亮度。

**觀察：**增加 40 是否讓陰影消失？通常只是整張加亮，亮區與陰影仍可能不同。請找出亮部是否失去細節。

## 單元二｜線性對比

以灰階 128 為中心，使用 `新值 = alpha × (原值 − 128) + 128`。`alpha > 1` 擴大差異，`0 < alpha < 1` 壓縮差異。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

alpha = 1.5
work = alpha * (gray.astype(np.float32) - 128) + 128
contrast = np.clip(work, 0, 255).astype(np.uint8)

cv2.imshow("Gray", gray)
cv2.imshow("Contrast", contrast)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

例如 100 與 160，倍率 1.5 時變為 86 與 176，亮度差由 60 增為 90。

`cv2.convertScaleAbs()` 另外會取絕對值，不能直接當成這裡「負值截成零」的完全等價替代。

**練習：**分別用 0.5、1.0、2.0。看細節差異，不只看圖片是否更黑白。

## 單元三｜直方圖

直方圖顯示每種灰階有多少像素。它描述分布，不描述位置；兩張結構不同的圖片也可能有相同直方圖。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import matplotlib.pyplot as plt

hist = cv2.calcHist([gray], [0], None, [256], [0, 256])
cv2.imshow("Gray", gray)
cv2.waitKey(0)
cv2.destroyAllWindows()

plt.plot(hist)
plt.xlabel("Gray value")
plt.ylabel("Pixel count")
plt.title("Histogram")
plt.xlim(0, 255)
plt.show()
```

先在圖片視窗按鍵結束，再查看直方圖視窗。這裡使用 Matplotlib 畫統計圖；照片處理結果仍用 OpenCV 視窗顯示。

| 第一次出現的寫法 | 意義 |
| --- | --- |
| `calcHist([gray], [0], None, [256], [0, 256])` | 計算第 0 通道的 256 格灰階分布 |
| `[gray]` | 這個 API 要求以串列提供來源影像 |
| `None` | 不使用區域遮罩，統計整張圖 |
| `[0, 256]` | 下界包含 0，上界不包含 256 |
| `import matplotlib.pyplot as plt` | 載入繪圖介面並命名為 `plt` |
| `plot()`、`xlabel()`、`ylabel()`、`title()` | 畫曲線與設定標籤 |
| `xlim()`、`show()` | 設定橫軸範圍並開啟圖表 |

**觀察：**白紙圖片常在高灰階有大量像素。這不表示每個低灰階像素都是音符。

## 單元四｜全域直方圖均衡化

均衡化依全圖亮度分布重新映射灰階，不是只加一個固定數字。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
equalized = cv2.equalizeHist(gray)

cv2.imshow("Gray", gray)
cv2.imshow("Equalized", equalized)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`cv2.equalizeHist(gray)` 接受單通道 8 位元灰階圖，回傳新影像。

**觀察：**較暗區域的細節是否變清楚？背景紋理是否也被強化？全域均衡化不等於移除陰影。

## 單元五｜CLAHE 局部對比

CLAHE 將圖片分區處理亮度分布，並限制過度增強。這能用來嘗試改善局部對比，但也可能強化紙張紋理與雜訊。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
enhanced = clahe.apply(gray)

cv2.imshow("Gray", gray)
cv2.imshow("CLAHE", enhanced)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新寫法 | 意義 |
| --- | --- |
| `cv2.createCLAHE(...)` | 建立 OpenCV 提供的處理物件，不是自行建立函式檔 |
| `clipLimit=2.0` | 限制對比增強的參數，不是「亮度乘 2」 |
| `tileGridSize=(8, 8)` | 分成 8 × 8 個區塊，不是每塊 8 × 8 像素 |
| `clahe.apply(gray)` | 用這組設定處理灰階圖並回傳結果 |

**練習：**固定區塊數，比較 `clipLimit` 為 1、2、4。下一次才改區塊數。

| 方法 | 主要改變 |
| --- | --- |
| 加亮／變暗 | 像素加上偏移值 |
| 線性對比 | 擴大或縮小亮度差 |
| 全域均衡化 | 依整張分布映射 |
| CLAHE | 依局部分布及限制條件映射 |

## 單元六｜固定門檻二值化

設定門檻 T，將每個像素分成兩類。`THRESH_BINARY` 的規則是大於 T 變 255，其餘包含等於 T 都變 0。

T = 127 時：`50 → 0`、`127 → 0`、`128 → 255`。二值化後不再保留原本亮暗層次。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
threshold_value, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
print("使用的門檻：", threshold_value)

cv2.imshow("Gray", gray)
cv2.imshow("Binary", binary)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 參數／回傳值 | 意義 |
| --- | --- |
| `gray` | 來源灰階影像 |
| `127` | 本次門檻，不是固定標準答案 |
| `255` | 指定輸出最大值 |
| `THRESH_BINARY` | 選用一般黑白二值化規則 |
| `threshold_value` | 實際使用的門檻值，不是成功與否的布林值 |
| `binary` | 處理後影像 |

**練習：**比較 80、127、180，說明為何門檻提高後，黑色區域可能增加。

---

## 單元七｜反相二值化與其他門檻規則

白紙上的黑字，在一般二值圖仍是黑色。要把字當作「白色前景」進行形態學或輪廓分析，可用反相二值化。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
_, inverse = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY_INV)

cv2.imshow("Binary", binary)
cv2.imshow("Inverse foreground", inverse)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`_` 是一般變數名，慣例用來表示這次不使用該回傳值。它不是省略解碼或改變二值化。

| 類型 | 像素 > T | 像素 ≤ T |
| --- | --- | --- |
| `THRESH_BINARY` | 最大值 | 0 |
| `THRESH_BINARY_INV` | 0 | 最大值 |
| `THRESH_TRUNC` | T | 保留原值 |
| `THRESH_TOZERO` | 保留原值 | 0 |
| `THRESH_TOZERO_INV` | 0 | 保留原值 |

後三種不保證只剩兩個值。下面完整範例用同一張圖比較它們。

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
_, truncated = cv2.threshold(gray, 127, 255, cv2.THRESH_TRUNC)
_, tozero = cv2.threshold(gray, 127, 255, cv2.THRESH_TOZERO)
_, tozero_inv = cv2.threshold(gray, 127, 255, cv2.THRESH_TOZERO_INV)

cv2.imshow("Gray", gray)
cv2.imshow("Trunc", truncated)
cv2.imshow("To zero", tozero)
cv2.imshow("To zero inverse", tozero_inv)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

## 單元八｜Otsu 自動門檻

Otsu 依全圖亮度分布選一個門檻，尋找使兩類的類內變異較小的分法。它仍是全域門檻，不會替圖片各位置選不同門檻，也不會理解文字與背景的語意。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
value, otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)
print("Otsu 選出的門檻：", value)

cv2.imshow("Gray", gray)
cv2.imshow("Otsu", otsu)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`|` 在此合併 OpenCV 旗標：「二值化方式」加上「自動估計門檻」。指定 Otsu 時，第二個參數 `0` 不是最後一定使用零，而是由演算法重新選值。

**觀察：**亮區與陰影區能否同時保留細字？有兩群明顯亮度的圖通常較適合，光線嚴重不均仍可能失敗。

## 單元九｜自適應平均門檻

用每個像素附近區域的平均值減去 C 作為局部門檻：`T = 鄰域平均 − C`。

假設周圍平均是 150，C = 10，局部門檻就是 140；中心像素 145 在 `THRESH_BINARY` 下會變白。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
adaptive = cv2.adaptiveThreshold(
    gray, 255, cv2.ADAPTIVE_THRESH_MEAN_C,
    cv2.THRESH_BINARY, 31, 10,
)

cv2.imshow("Gray", gray)
cv2.imshow("Adaptive mean", adaptive)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新參數 | 意義 |
| --- | --- |
| `ADAPTIVE_THRESH_MEAN_C` | 以鄰域算術平均計算門檻 |
| `31` | `blockSize`，使用 31 × 31 區域；必須是大於 1 的奇數 |
| `10` | C，從區域估計值扣除的常數，不是區域高度 |

這個函式回傳一張影像，不是 `threshold()` 的兩個回傳值。輸入必須是 8 位元單通道影像。

**練習：**固定 C，改成 15、31、51。再固定區域大小，調整 C。使用一般二值方式時，C 增大會使局部門檻下降，通常讓白色變多。

## 單元十｜自適應高斯門檻

高斯方法讓接近中心的像素有較大權重，再減去 C。仍然產生局部門檻，不是直接輸出模糊後圖片。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
adaptive = cv2.adaptiveThreshold(
    gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY, 31, 10,
)

cv2.imshow("Gray", gray)
cv2.imshow("Adaptive Gaussian", adaptive)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

這次新代碼是 `ADAPTIVE_THRESH_GAUSSIAN_C`，其他參數和上一單元相同。

| 方法 | 門檻如何決定 |
| --- | --- |
| 固定門檻 | 自行指定全圖一個值 |
| Otsu | 由全圖分布估一個值 |
| 自適應平均 | 各區域平均減 C |
| 自適應高斯 | 各區域高斯加權減 C |

自適應方法可能把均勻的大面積深色區域中心判成背景。結果較有線條，不代表它已是完整的物體分割。

[OpenCV：門檻處理](https://docs.opencv.org/4.x/d7/d4d/tutorial_py_thresholding.html)

## 單元十一｜椒鹽雜訊

椒鹽雜訊是像素被黑或白取代。先在同一張測試圖加入已知比例的雜點，才知道濾波移除了什麼。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

rng = np.random.default_rng(42)
chance = rng.random(gray.shape)
noisy = gray.copy()
noisy[chance < 0.02] = 0
noisy[chance > 0.98] = 255

cv2.imshow("Gray", gray)
cv2.imshow("Salt and pepper", noisy)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新寫法 | 意義 |
| --- | --- |
| `default_rng(42)` | 建立亂數產生器；固定種子方便同環境重做比較 |
| `rng.random(gray.shape)` | 產生同形狀、位於 `[0, 1)` 的亂數 |
| `chance < 0.02` | 約 2% 的位置設黑 |
| `chance > 0.98` | 約 2% 的位置設白 |

合計期望約 4% 被選中，實際數量不一定恰好 4%；本來就黑白的像素被選中後可能沒變。這不是訊號雜訊比 SNR。

**觀察：**放大看，這些點是突然的極端值，不是整張均勻變暗。

## 單元十二｜高斯雜訊

高斯雜訊是在像素上加上服從常態分布的擾動。平均 0 是擾動的中心，標準差控制變化幅度。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

rng = np.random.default_rng(42)
noise = rng.normal(loc=0, scale=15, size=gray.shape)
noisy = np.clip(gray.astype(np.float32) + noise, 0, 255).astype(np.uint8)

cv2.imshow("Gray", gray)
cv2.imshow("Gaussian noise", noisy)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`normal(loc, scale, size)` 的 `loc` 是平均，`scale` 是標準差，不是變異數；`size` 指定陣列形狀。這個例子直接以 0～255 灰階尺度的 15 作為標準差。

**練習：**把標準差改成 5 和 30。加入後再截斷數值，輸出誤差不再嚴格服從未截斷的高斯分布。

## 單元十三｜平均濾波

一個小視窗叫作核或 kernel。3 × 3 平均濾波把鄰近九個數值相加除以 9，用來替換中心值。

如果鄰域八個值都是 100、一個是 255，平均約 117.2；極端值影響變小，但也擴散到附近。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
blurred = cv2.blur(gray, (3, 3))

cv2.imshow("Gray", gray)
cv2.imshow("Mean filter", blurred)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`cv2.blur(影像, (核寬, 核高))` 回傳平均後圖片。可改成 `(5, 5)`、`(9, 9)` 比較；本章使用奇數核方便對準中心。

邊界像素缺少完整鄰居，OpenCV 會按邊界規則延伸取樣；預設不是一律補黑。

**觀察：**文字邊緣是否變鈍？不要只用「更平滑」判斷好壞。

## 單元十四｜自訂加權濾波

平均濾波每個鄰居權重相同，也可以讓中心更重要。以下權重總和為 16，除以 16 後總和為 1，均勻區域的亮度才不會單純被放大。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

kernel = np.array([[1, 2, 1], [2, 4, 2], [1, 2, 1]], dtype=np.float32) / 16
weighted = cv2.filter2D(gray, -1, kernel)

cv2.imshow("Gray", gray)
cv2.imshow("Weighted filter", weighted)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`filter2D(來源, 輸出深度, 核)` 將核與鄰近像素逐項相乘相加。`-1` 表示輸出深度沿用輸入。

嚴格來說這個 API 執行相關運算，不先翻轉核；這裡的核對稱，與翻轉後捲積相同。核含負權重時，不能隨意用 `uint8` 保存負結果。

**手算：**八個鄰居 100、中心 200，這個核的輸出是 `(12 × 100 + 4 × 200) / 16 = 125`。

## 單元十五｜高斯濾波

高斯濾波也使用加權平均，離中心較近的像素通常權重較高。它能平滑高頻變化，但不能區分雜訊與真正細線。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
gaussian = cv2.GaussianBlur(gray, (5, 5), sigmaX=0)

cv2.imshow("Gray", gray)
cv2.imshow("Gaussian filter", gaussian)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 參數 | 說明 |
| --- | --- |
| `(5, 5)` | 核的寬、高；本例使用正奇數 |
| `sigmaX=0` | 依核大小推導使用的標準差，不是「完全不模糊」 |
| `sigmaY` | 可另外指定垂直標準差，通常先使用預設 |

高斯「雜訊」是被加入的擾動分布；高斯「濾波」是計算鄰域加權。兩者不是互相完全抵消的一對操作。

## 單元十六｜中位數濾波

把鄰域數值排序，取中間那一個作為中心結果，不是把所有值取平均。八個 100、一個 255，3 × 3 中位數就是 100。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

rng = np.random.default_rng(42)
chance = rng.random(gray.shape)
noisy = gray.copy()
noisy[chance < 0.02] = 0
noisy[chance > 0.98] = 255
median = cv2.medianBlur(noisy, 3)

cv2.imshow("Gray", gray)
cv2.imshow("Noisy", noisy)
cv2.imshow("Median filter", median)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`cv2.medianBlur(影像, 核邊長)` 的第二個參數是單一整數 `3`，不是 `(3, 3)`。本例使用大於 1 的奇數。

中位數常適合孤立椒鹽點，但也可能移除真正的小點、變形細線。對樂譜，附點消失就會改變意義。

| 濾波方法 | 計算 | 主要提醒 |
| --- | --- | --- |
| 平均 `blur` | 鄰域平均 | 邊緣容易模糊 |
| 加權 `filter2D` | 自訂加權和 | 檢查權重總和與輸出型別 |
| 高斯 `GaussianBlur` | 高斯加權 | 細線也可能被平滑 |
| 中位數 `medianBlur` | 排序後取中間 | 非線性，可能去掉重要小細節 |

[OpenCV：平滑與濾波](https://docs.opencv.org/4.x/d4/d13/tutorial_py_filtering.html)

## 單元十七｜形態學的前景與結構元素

以下統一讓「要保留的物體」在二值圖中是白色，背景是黑色。白紙黑字可用 `THRESH_BINARY_INV` 反相。

形態學使用結構元素決定鄰域形狀，不是把它的值相乘取平均。對平坦的結構元素，侵蝕相當於取鄰域最小值，膨脹相當於取最大值。

### 完整範例：檢查結構元素

```python
import cv2
import numpy as np

square = np.ones((3, 3), dtype=np.uint8)
cross = cv2.getStructuringElement(cv2.MORPH_CROSS, (3, 3))
ellipse = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
print("Square：\n", square)
print("Cross：\n", cross)
print("Ellipse：\n", ellipse)
```

`getStructuringElement(形狀, (寬, 高))` 建立結構元素。非零位置表示納入這個鄰域。

| 形狀 | 代碼 |
| --- | --- |
| 矩形 | `MORPH_RECT` |
| 十字形 | `MORPH_CROSS` |
| 橢圓形近似 | `MORPH_ELLIPSE` |

這段先印數字，後面每一個操作都會顯示圖片。開始前先確認白色前景是否正確；黑字白底直接做侵蝕時，視覺上黑字可能反而變粗，因為縮小的是白色。

## 單元十八｜侵蝕

白色前景邊界縮小。3 × 3 全一核移過時，只有所涵蓋的位置都滿足白色，中心才保留白色；小白點可能被移除。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
kernel = np.ones((3, 3), dtype=np.uint8)
result = cv2.erode(binary, kernel, iterations=1)

cv2.imshow("White foreground", binary)
cv2.imshow("Result", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`erode(來源, 核, iterations=1)` 的 `iterations` 是重複次數，不是核大小。

**觀察與練習：**比較細線、附點、孔洞與物體間隔，再將核改成 5 × 5。一次只改核大小，不要同時改二值化門檻。

---

## 單元十九｜膨脹

白色前景邊界擴大。鄰域中有白色就可能讓中心成為白色，可接起小間隔，也可能把不同物體黏在一起。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
kernel = np.ones((3, 3), dtype=np.uint8)
result = cv2.dilate(binary, kernel, iterations=1)

cv2.imshow("White foreground", binary)
cv2.imshow("Result", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`dilate()` 與 `erode()` 使用相似參數，但改變方向相反。

**觀察與練習：**比較細線、附點、孔洞與物體間隔，再將核改成 5 × 5。一次只改核大小，不要同時改二值化門檻。

---

## 單元二十｜開運算

開運算是先侵蝕、再膨脹。可移除小白點；後面的膨脹不會把被整個刪掉的附點神奇還原。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
kernel = np.ones((3, 3), dtype=np.uint8)
result = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)

cv2.imshow("White foreground", binary)
cv2.imshow("Result", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`morphologyEx(來源, 運算代碼, 核)` 執行組合形態學，`MORPH_OPEN` 指定開運算。

**觀察與練習：**比較細線、附點、孔洞與物體間隔，再將核改成 5 × 5。一次只改核大小，不要同時改二值化門檻。

---

## 單元二十一｜閉運算

閉運算是先膨脹、再侵蝕。可補白色前景中的小黑洞或小間隔，也可能讓相鄰符號連在一起。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
kernel = np.ones((3, 3), dtype=np.uint8)
result = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)

cv2.imshow("White foreground", binary)
cv2.imshow("Result", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`MORPH_CLOSE` 指定閉運算，不是將視窗關閉。

**觀察與練習：**比較細線、附點、孔洞與物體間隔，再將核改成 5 × 5。一次只改核大小，不要同時改二值化門檻。

| 操作 | 順序 | 對白色前景常見效果 |
| --- | --- | --- |
| 侵蝕 | 取鄰域最小 | 縮小、細化、去小白點 |
| 膨脹 | 取鄰域最大 | 擴大、接起小斷裂 |
| 開運算 | 侵蝕 → 膨脹 | 去掉部分小白前景 |
| 閉運算 | 膨脹 → 侵蝕 | 補部分小黑孔洞與間隙 |

是否符合需求，取決於前景定義、結構元素與物體尺度；不是「開運算去所有雜訊，閉運算修所有斷線」。

[OpenCV：形態學](https://docs.opencv.org/4.x/d9/d61/tutorial_py_morphological_ops.html)

## 綜合實作｜同一張圖片的處理比較

### 引導思考

先用同一張灰階圖當基準。觀察 CLAHE 前後，再從溫和高斯濾波結果分出固定門檻、Otsu、自適應平均與自適應高斯四條支線。形態學只在另一張白色前景圖上比較開／閉運算，不把每個方法都串到 OMR 輸入。

### 完整程式：`lesson06_compare.py`

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
enhanced = clahe.apply(gray)
smooth = cv2.GaussianBlur(enhanced, (3, 3), sigmaX=0)
_, fixed = cv2.threshold(smooth, 127, 255, cv2.THRESH_BINARY)
otsu_value, otsu = cv2.threshold(smooth, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)
mean = cv2.adaptiveThreshold(smooth, 255, cv2.ADAPTIVE_THRESH_MEAN_C,
                             cv2.THRESH_BINARY, 31, 10)
gaussian = cv2.adaptiveThreshold(smooth, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                 cv2.THRESH_BINARY, 31, 10)
_, foreground = cv2.threshold(smooth, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
opened = cv2.morphologyEx(foreground, cv2.MORPH_OPEN, kernel)
closed = cv2.morphologyEx(foreground, cv2.MORPH_CLOSE, kernel)

print("Otsu 門檻：", otsu_value)
for title, result in [("CLAHE", enhanced), ("Gaussian blur", smooth),
                      ("Fixed", fixed), ("Otsu", otsu),
                      ("Adaptive mean", mean), ("Adaptive Gaussian", gaussian),
                      ("Foreground", foreground), ("Opening", opened), ("Closing", closed)]:
    print("目前比較：", title)
    cv2.imshow("Gray baseline", gray)
    cv2.imshow("Current result", result)
    cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 怎麼看結果

每按一次鍵看下一個方法。這裡用 A 章學過的 `for` 迴圈切換視窗內容，沒有隱藏處理步驟的自訂函式。回到某個結果時，可重跑或調整串列順序。

| 觀察項目 | 要記錄的內容 |
| --- | --- |
| 文字／音符 | 是否完整，有沒有細節消失 |
| 五線與細線 | 是否變淡、斷裂或變粗 |
| 小點 | 是被去除的雜訊，還是重要附點 |
| 背景 | 陰影是否仍在，紋理是否被放大 |
| 物體間隔 | 是否意外連成一塊 |

### 修改練習

先讓 `enhanced = gray.copy()`，比較不做 CLAHE 的版本；下一次才改濾波核。再加入中位數支線，使用同一份椒鹽雜訊圖比較平均與中位數。

各方法的畫面是比較素材，不是辨識準確率。需要證明 OMR 改善，仍要用原圖與處理候選圖各做一次辨識，核對音符與節奏結果。
