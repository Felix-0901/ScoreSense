# 第 6 章｜灰階、對比、二值化與雜訊

影像可能太暗、光照不均，也可能混入亮暗雜點。不同問題需要不同方法：調亮不等於去雜訊，二值化不等於找到物體，形態學也不會知道哪些小點是雜訊、哪些是重要內容。

本章以一般文字、幾何圖形與細線比較方法。每個方法都先說明它改變什麼，再實際產生一張結果圖。

## 學習目標

- 使用灰階、亮度、對比與直方圖理解影像數值。
- 比較全域均衡化、CLAHE、固定門檻、Otsu 與兩種自適應門檻。
- 產生椒鹽與高斯雜訊，理解平均、加權、高斯與中位數濾波。
- 分辨侵蝕、膨脹、開運算與閉運算。
- 建立保留原圖、分支比較與參數紀錄的影像實驗。

## 範例準備

使用 **Python 3.11** 與既有 NumPy、OpenCV、Matplotlib。所有處理結果存檔，不需要 GUI 視窗。

先將以下程式存成 **`lesson06_common.py`**，再把各小範例存成同資料夾中的其他 `.py`。本章的共用檔案是完整的，不依賴第 5 章的檔案。

`make_demo()` 回傳乾淨圖與模擬陰影圖，`make_mask()` 建立帶有缺口與小點的二值形狀，`new_run()` 每次建立新輸出目錄。這些是已知條件的合成素材，不是已驗證的辨識資料集。

```python
from pathlib import Path
from tempfile import mkdtemp
import cv2
import numpy as np

BASE_DIR = Path(__file__).resolve().parent


def new_run(label):
    root = BASE_DIR / "output" / "lesson06"
    root.mkdir(parents=True, exist_ok=True)
    return Path(mkdtemp(prefix=f"{label}_", dir=str(root)))


def make_demo():
    image = np.full((240, 400), 235, dtype=np.uint8)
    cv2.rectangle(image, (35, 35), (130, 95), 35, -1)
    cv2.circle(image, (205, 65), 28, 40, 2)
    cv2.putText(image, "ABC", (270, 80), cv2.FONT_HERSHEY_SIMPLEX, 0.8, 30, 2)
    for y in [140, 150, 160, 170, 180]:
        image[y:y + 1, 30:370] = 30
    cv2.circle(image, (220, 205), 2, 20, -1)
    illumination = np.linspace(0.45, 1.0, image.shape[1], dtype=np.float32)[None, :]
    shadow = np.rint(image.astype(np.float32) * illumination).astype(np.uint8)
    return image, shadow


def make_mask():
    mask = np.zeros((120, 200), dtype=np.uint8)
    mask[25:95, 45:100] = 255
    mask[25:95, 104:155] = 255
    mask[50:53, 75:78] = 0
    mask[10, 10] = 255
    mask[105, 180] = 255
    return mask


def save_png(path, image):
    if image.dtype != np.uint8 or image.size == 0:
        raise ValueError("需要非空的 uint8 影像")
    ok, buffer = cv2.imencode(".png", np.ascontiguousarray(image))
    if not ok:
        raise ValueError("PNG 編碼失敗")
    with Path(path).open("xb") as file:
        file.write(buffer.tobytes())
```

## 單元一｜灰階與數值範圍

彩圖轉灰階會將三個色彩通道轉成一個亮暗值。對常見 BGR 影像，換算近似為 `Y = 0.114B + 0.587G + 0.299R`。不同顏色可能變成相近的灰階，因此灰階化也會捨棄資訊。

### 範例：彩色像素轉灰階

```python
import cv2
import numpy as np

bgr = np.array([[[255, 0, 0], [0, 255, 0], [0, 0, 255]]], dtype=np.uint8)
gray = cv2.cvtColor(bgr, cv2.COLOR_BGR2GRAY)
print("BGR 形狀：", bgr.shape)
print("灰階形狀：", gray.shape)
print("灰階值：", gray.tolist())
```

預期灰階值約為 `[[29, 150, 76]]`。本章之後的影像方法都以二維 `uint8` 灰階圖為主，避免把不同通道或 `0～1` 浮點陣列誤當成相同輸入。

**想一想：**兩個顏色轉灰階後幾乎相同，是否還能只靠灰階門檻把它們分開？

## 單元二｜亮度與對比

### 2-1｜亮度偏移

`g = f + beta` 為每個像素加上同一數值。正的 `beta` 變亮，負值變暗，最後限制在 `0～255`。

### 範例：將陰影圖加亮

```python
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("brightness")
_, gray = make_demo()
bright = np.clip(gray.astype(np.float32) + 40, 0, 255).astype(np.uint8)
save_png(run / "original.png", gray)
save_png(run / "bright.png", bright)
print("平均值：", float(gray.mean()), float(bright.mean()))
print(run)
```

加亮會同時影響亮區與暗區，不會自動消除左暗右亮的差異；原本較亮的背景還可能被截成全白。

### 2-2｜線性對比

`g = alpha × f + beta` 中，`alpha` 改變亮度差異的比例。以中間灰階 `128` 為中心時，可寫成 `g = alpha × (f-128) + 128`。

### 範例：以中灰為中心提高對比

```python
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("contrast")
_, gray = make_demo()
work = 1.5 * (gray.astype(np.float32) - 128) + 128
contrast = np.rint(work).clip(0, 255).astype(np.uint8)
save_png(run / "original.png", gray)
save_png(run / "contrast.png", contrast)
print(run)
```

大於 `128` 的值更亮，小於 `128` 的值更暗。過大的倍率會截斷兩端細節。

`cv2.convertScaleAbs()` 還包含取絕對值，不等於單純的「線性變換後截斷」。這裡明確用浮點計算與 `clip()`，避免把負值反射成亮值。

## 單元三｜直方圖與對比強化

### 3-1｜先看亮度分布

直方圖的橫軸是灰階值，縱軸是像素數量。它能顯示資料集中在哪些亮度，卻不能告訴你那些像素位於哪裡。

### 範例：比較均勻背景與陰影的直方圖

```python
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from lesson06_common import make_demo, new_run

run = new_run("histogram")
clean, shadow = make_demo()
for name, image in [("clean", clean), ("shadow", shadow)]:
    histogram = np.bincount(image.ravel(), minlength=256)
    fig, ax = plt.subplots()
    ax.plot(np.arange(256), histogram)
    ax.set(xlabel="Gray value", ylabel="Pixel count", title=name, xlim=(0, 255))
    fig.savefig(run / f"{name}_histogram.png", dpi=120)
    plt.close(fig)
print(run)
```

乾淨圖的大量背景像素集中在同一亮度；陰影圖的背景分散在較廣範圍。不要因為分布較寬，就認為畫面一定更好。

### 3-2｜全域直方圖均衡化

`equalizeHist()` 依全圖累積亮度分布重新映射像素，適合觀察全域對比調整。它不是單純加亮，也不會知道哪些差異是紙張紋理。

### 範例：全域均衡化

```python
import cv2
from lesson06_common import make_demo, new_run, save_png

run = new_run("equalize")
_, gray = make_demo()
enhanced = cv2.equalizeHist(gray)
save_png(run / "original.png", gray)
save_png(run / "equalized.png", enhanced)
print(run)
```

觀察左暗右亮是否仍存在，以及原本不明顯的背景差異是否被放大。全域均衡化不等於估計並移除照明。

### 3-3｜CLAHE：限制對比的局部均衡化

CLAHE 在局部區塊處理亮度分布，再銜接區塊結果。`clipLimit` 限制直方圖峰值的增強程度，`tileGridSize=(8,8)` 表示分成 **8 × 8 個區塊**，不是每塊只有 8 × 8 個像素。

### 範例：局部對比調整

```python
import cv2
from lesson06_common import make_demo, new_run, save_png

run = new_run("clahe")
_, gray = make_demo()
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
enhanced = clahe.apply(gray)
save_png(run / "original.png", gray)
save_png(run / "clahe.png", enhanced)
print(run)
```

**觀察：**比較陰影中的文字是否容易看清楚，以及背景是否出現更多變化。調整 `clipLimit` 或區塊數量時，每次只改一個條件。CLAHE 可能放大雜訊，不是所有照片都需要套用。

## 單元四｜雜訊：先知道加入了什麼

### 4-1｜椒鹽雜訊

椒鹽雜訊模擬像素被黑色或白色取代。下面的 `amount=0.04` 表示選中約 4% 的像素位置，不是訊號雜訊比 SNR。

使用不重複抽樣，避免同一位置重複抽到而讓比例難以解釋。原像素本來就可能是黑或白，因此「選中位置數」與「數值真的改變的位置數」也可能不同。

### 範例：加入椒鹽雜訊

```python
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("salt_pepper")
clean, _ = make_demo()
rng = np.random.default_rng(42)
noisy = clean.copy()
count = round(0.04 * clean.size)
indices = rng.choice(clean.size, size=count, replace=False)
noisy.flat[indices[:count // 2]] = 0
noisy.flat[indices[count // 2:]] = 255
save_png(run / "clean.png", clean)
save_png(run / "noisy.png", noisy)
print("選中位置數：", count)
print("實際不同數：", np.count_nonzero(noisy != clean))
print(run)
```

### 4-2｜高斯雜訊

高斯雜訊的擾動值服從常態分布。平均值 `0` 表示抽樣擾動的中心不偏亮或偏暗，標準差 `sigma` 控制散布幅度；單張有限樣本的平均不一定恰好為零。

### 範例：加入高斯雜訊

```python
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("gaussian_noise")
clean, _ = make_demo()
rng = np.random.default_rng(42)
noise = rng.normal(loc=0.0, scale=12.0, size=clean.shape)
noisy = np.rint(clean.astype(np.float32) + noise).clip(0, 255).astype(np.uint8)
save_png(run / "clean.png", clean)
save_png(run / "noisy.png", noisy)
print("擾動平均與標準差：", float(noise.mean()), float(noise.std()))
print(run)
```

先用浮點數加上可能為負的擾動，最後才限制範圍。截斷與取整之後，圖片上實際保留的誤差不再完全服從原本的高斯分布。

固定亂數種子方便重做同一個實驗，不代表真實相機雜訊也完全符合這個模型。

## 單元五｜鄰域、kernel 與濾波

濾波不是只看一個像素，而是使用周圍一小塊鄰域計算新的值。`3 × 3` 的核一次參考 9 個位置，常以中心位置作為輸出位置。

### 5-1｜手算平均與加權平均

以下鄰域中央是 `100`，其餘都是 `10`：平均為 `(100+8×10)/9 = 20`。如果中央權重較高，它對結果的影響也較大。

### 範例：手算與陣列計算核對

```python
import numpy as np

patch = np.array([[10, 10, 10], [10, 100, 10], [10, 10, 10]], dtype=np.float32)
weights = np.array([[1, 2, 1], [2, 4, 2], [1, 2, 1]], dtype=np.float32) / 16
print("平均：", float(patch.mean()))
print("加權平均：", float(np.sum(patch * weights)))
print("權重總和：", float(weights.sum()))
```

加權結果是 `32.5`。平均核的權重總和設成 `1`，可以使固定亮度區域維持固定亮度。

影像邊界外沒有像素，因此濾波需要補邊規則。下面明確使用 `BORDER_REFLECT_101` 的鏡射方式；邊界結果不應套用「有完整九個原始鄰居」的手算假設。

### 5-2｜算術平均濾波

`cv2.blur()` 對鄰域取平均。它能平滑隨機起伏，但邊界、文字與細線也會被混合。

### 範例：平均濾波

```python
import cv2
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("mean_filter")
clean, _ = make_demo()
rng = np.random.default_rng(42)
noisy = np.rint(clean.astype(np.float32) + rng.normal(0, 12, clean.shape)).clip(0, 255).astype(np.uint8)
filtered = cv2.blur(noisy, (3, 3), borderType=cv2.BORDER_REFLECT_101)
save_png(run / "noisy.png", noisy)
save_png(run / "mean.png", filtered)
print(run)
```

### 5-3｜自訂加權核

`filter2D()` 可以使用自己的核。OpenCV 這個函式直接按核對應位置相乘加總，屬於互相關；數學上的卷積還會翻轉核。對本例左右上下對稱的核，兩者結果相同。

### 範例：加權平滑

```python
import cv2
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("weighted_filter")
clean, _ = make_demo()
kernel = np.array([[1, 2, 1], [2, 4, 2], [1, 2, 1]], dtype=np.float32) / 16
filtered = cv2.filter2D(clean, ddepth=-1, kernel=kernel, borderType=cv2.BORDER_REFLECT_101)
save_png(run / "original.png", clean)
save_png(run / "weighted.png", filtered)
print(run)
```

這個核可用來理解中央較重的平滑，但不能把它當成任意 `sigma` 的唯一高斯核。

### 5-4｜高斯濾波

高斯核以距離中心的遠近決定權重。核的大小與 `sigmaX` 都會影響平滑程度；本章使用正奇數邊長。`sigmaX=0` 讓 OpenCV 由核大小估計參數。

### 範例：比較高斯核大小

```python
import cv2
from lesson06_common import make_demo, new_run, save_png

run = new_run("gaussian_filter")
clean, _ = make_demo()
save_png(run / "original.png", clean)
for size in [3, 5, 9]:
    filtered = cv2.GaussianBlur(clean, (size, size), sigmaX=0,
                                borderType=cv2.BORDER_REFLECT_101)
    save_png(run / f"gaussian_{size}.png", filtered)
print(run)
```

觀察底部一像素細線與小圓點。核越大，通常平滑越強，但不代表越適合後續辨識。高斯濾波與高斯雜訊是不同概念：一個是處理方法，一個是擾動模型。

### 5-5｜中位數濾波

中位數濾波將鄰域數值排序，再取中央值，不是加權平均。對稀疏黑白突點經常比平均更合適，但也可能移除真實的小點或細線。

### 範例：移除椒鹽雜點

```python
import cv2
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("median_filter")
clean, _ = make_demo()
rng = np.random.default_rng(42)
noisy = clean.copy()
indices = rng.choice(clean.size, size=round(clean.size * 0.04), replace=False)
half = len(indices) // 2
noisy.flat[indices[:half]] = 0
noisy.flat[indices[half:]] = 255
filtered = cv2.medianBlur(noisy, 3)
save_png(run / "noisy.png", noisy)
save_png(run / "median.png", filtered)
print("中位數手算：", np.median([10, 10, 10, 10, 255, 10, 10, 10, 10]))
print(run)
```

中位數手算結果是 `10`，不是平均值。`medianBlur()` 的常用核邊長是大於 1 的奇數；這裡使用 `uint8` 與 `3`。

### 小練習

同一張椒鹽圖分別做平均、高斯與中位數濾波。觀察雜點、文字外緣與小圓點，不要只看背景是否平滑。再把雜訊比例從 `0.04` 改成 `0.15`，比較結論是否仍相同。

## 單元六｜固定門檻與反相二值化

### 6-1｜固定門檻

`THRESH_BINARY` 的規則是：大於 `T` 設成 `255`，小於或等於 `T` 設成 `0`。等於門檻時屬於哪邊，會影響邊界測試。

### 範例：先驗證門檻，再處理圖片

```python
import cv2
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("fixed_threshold")
values = np.array([[159, 160, 161]], dtype=np.uint8)
used, sample = cv2.threshold(values, 160, 255, cv2.THRESH_BINARY)
print("使用門檻：", used)
print("測試結果：", sample.tolist())
_, gray = make_demo()
for threshold in [100, 140, 180, 220]:
    _, binary = cv2.threshold(gray, threshold, 255, cv2.THRESH_BINARY)
    save_png(run / f"binary_{threshold}.png", binary)
print(run)
```

測試結果應為 `[[0, 0, 255]]`。第一個回傳值是使用的門檻數值，不是成功與否的布林值。

對陰影圖，一個門檻可能讓暗背景被判成黑色，也可能讓亮區淺色內容消失。

### 6-2｜反相二值化

`THRESH_BINARY_INV` 把上面的黑白對調。黑色文字在白底上時，反相後可用白色表示前景，方便形態學與座標提取。

### 範例：白色前景遮罩

```python
import cv2
import numpy as np
from lesson06_common import make_demo, new_run, save_png

run = new_run("inverse_threshold")
clean, _ = make_demo()
_, foreground = cv2.threshold(clean, 160, 255, cv2.THRESH_BINARY_INV)
save_png(run / "original.png", clean)
save_png(run / "foreground.png", foreground)
print("前景像素：", np.count_nonzero(foreground))
print(run)
```

白色是本次的前景約定，不代表 OpenCV 理解「這是文字」。在白底圖上直接做侵蝕，與反相成白色文字後再做侵蝕，對可見文字的影響會相反。

## 單元七｜Otsu：由分布選擇全域門檻

Otsu 搜尋能讓兩群灰階在統計上分得較開的門檻，等價於最小化加權類內變異。直觀上，它試著找一個切點，讓切點兩邊各自較集中。

它仍然使用**全圖同一個門檻**，不是辨識模型，也不保證把真正物體與背景分對。前景與背景亮度差異明確時通常較容易使用；光照不均可能破壞這個條件。

### 範例：乾淨圖與陰影圖各估一次

```python
import cv2
from lesson06_common import make_demo, new_run, save_png

run = new_run("otsu")
clean, shadow = make_demo()
for name, gray in [("clean", clean), ("shadow", shadow)]:
    threshold, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)
    save_png(run / f"{name}_binary.png", binary)
    print(name, "門檻：", threshold)
print(run)
```

第二個參數填 `0`，是因為啟用 Otsu 後由演算法計算門檻。`|` 合併兩個旗標。比較兩張結果時，也要打開原圖，避免把陰影造成的大片黑色誤認成前景。

## 單元八｜自適應二值化

### 8-1｜局部算術平均

每個位置使用周圍區域的平均值減去 `C` 作為門檻：`T(x,y) = 局部平均 - C`。`blockSize` 是正方形鄰域邊長，必須是大於 1 的奇數。

例如區域平均為 `120`、`C=10`，門檻就是 `110`，不是把區域改成 `blockSize × C`。

### 範例：局部平均門檻

```python
import cv2
from lesson06_common import make_demo, new_run, save_png

run = new_run("adaptive_mean")
_, gray = make_demo()
binary = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_MEAN_C,
                               cv2.THRESH_BINARY, blockSize=31, C=10)
save_png(run / "original.png", gray)
save_png(run / "mean_binary.png", binary)
print(run)
```

### 8-2｜局部高斯加權

高斯加權的方法仍是局部門檻，但附近位置權重較高。它不是直接對圖片做一次高斯模糊後就結束，而是利用局部估計值完成二值比較。

### 範例：高斯加權門檻

```python
import cv2
from lesson06_common import make_demo, new_run, save_png

run = new_run("adaptive_gaussian")
_, gray = make_demo()
binary = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                               cv2.THRESH_BINARY, blockSize=31, C=10)
save_png(run / "original.png", gray)
save_png(run / "gaussian_binary.png", binary)
print(run)
```

### 8-3｜一次只改一個參數

在 `THRESH_BINARY` 模式下，`C` 增大會降低比較門檻，傾向讓更多位置變白。黑色細節可能因此減少；不是 `C` 越大就越清楚。

### 範例：參數比較

```python
import cv2
from lesson06_common import make_demo, new_run, save_png

run = new_run("adaptive_parameters")
_, gray = make_demo()
for block in [15, 31, 51]:
    result = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                   cv2.THRESH_BINARY, block, 10)
    save_png(run / f"block_{block}_C10.png", result)
for constant in [5, 10, 20]:
    result = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                   cv2.THRESH_BINARY, 31, constant)
    save_png(run / f"block31_C{constant}_comparison.png", result)
print(run)
```

區域太小可能追著紋理變化，太大則可能無法適應快速變化的照明。照片縮小後，同樣的 `31` 像素也代表不同的相對範圍，所以調參時必須記錄影像尺寸。

## 單元九｜形態學與結構元素

形態學根據鄰域形狀處理前景。本單元一律使用 **白色 255 前景、黑色 0 背景**，且小範例的物體離影像邊界有足夠距離。

`getStructuringElement()` 的尺寸是 `(寬, 高)`；`np.ones((高, 寬))` 則沿用 NumPy 的形狀順序。核的形狀、大小與反覆次數都會改變結果。

### 範例：矩形、十字與橢圓核

```python
import cv2

for name, shape in [("rect", cv2.MORPH_RECT), ("cross", cv2.MORPH_CROSS),
                    ("ellipse", cv2.MORPH_ELLIPSE)]:
    kernel = cv2.getStructuringElement(shape, (5, 5))
    print(name)
    print(kernel)
```

### 9-1｜侵蝕

對白色前景，侵蝕要求核覆蓋的有效鄰域都屬於前景，中心才保留為白色。結果通常縮小白色區域，也可能移除小白點。

### 範例：侵蝕前景

```python
import cv2
import numpy as np
from lesson06_common import make_mask, new_run, save_png

run = new_run("erosion")
mask = make_mask()
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
result = cv2.erode(mask, kernel, iterations=1)
save_png(run / "original.png", mask)
save_png(run / "eroded.png", result)
print("白色像素：", np.count_nonzero(mask), np.count_nonzero(result))
print(run)
```

### 9-2｜膨脹

對白色前景，膨脹只要核的有效鄰域有前景，中心就可能變白。它能加粗或連接鄰近區域，也可能把原本分開的物體黏在一起。

### 範例：膨脹前景

```python
import cv2
import numpy as np
from lesson06_common import make_mask, new_run, save_png

run = new_run("dilation")
mask = make_mask()
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
result = cv2.dilate(mask, kernel, iterations=1)
save_png(run / "original.png", mask)
save_png(run / "dilated.png", result)
print("白色像素：", np.count_nonzero(mask), np.count_nonzero(result))
print(run)
```

### 9-3｜開運算

開運算是 **先侵蝕，再膨脹**，常用來去除比核小的白色突出或雜點。它不會完整還原侵蝕前的所有細節。

### 範例：開運算與手動兩步比較

```python
import cv2
import numpy as np
from lesson06_common import make_mask, new_run, save_png

run = new_run("opening")
mask = make_mask()
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
opened = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)
two_steps = cv2.dilate(cv2.erode(mask, kernel), kernel)
save_png(run / "original.png", mask)
save_png(run / "opened.png", opened)
print("兩種寫法一致：", np.array_equal(opened, two_steps))
print(run)
```

### 9-4｜閉運算

閉運算是 **先膨脹，再侵蝕**，常用來填小黑洞或連接小缺口，也可能把不應連接的區域合併。

### 範例：閉運算與手動兩步比較

```python
import cv2
import numpy as np
from lesson06_common import make_mask, new_run, save_png

run = new_run("closing")
mask = make_mask()
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
closed = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)
two_steps = cv2.erode(cv2.dilate(mask, kernel), kernel)
save_png(run / "original.png", mask)
save_png(run / "closed.png", closed)
print("兩種寫法一致：", np.array_equal(closed, two_steps))
print(run)
```

### 如何決定要不要使用？

先指出想移除或填補的結構大小，再選核。不要因為影像有小點就全部刪除：標點、細線、小圓點都可能是內容。

對樂譜而言，附點、符桿與五線也可能比核小，所以形態學結果先當成比較分支，不直接取代原圖。

## 綜合實作｜建立影像方法比較實驗

### 一、規劃資料流

這次不是把所有方法一路串到底，而是由同一張灰階圖建立不同分支。目的在於說明「選哪種方法」的理由，而不是證明處理步驟越多越好。

```text
原始灰階 ──→ 亮度／線性對比／均衡化／CLAHE
    │
    ├──→ 人工加入已知雜訊 → 各種濾波 → 比較誤差與細節
    │
    └──→ 溫和高斯濾波 → 固定／Otsu／自適應門檻
                              ↓
                         白色前景遮罩
                              ↓
                     侵蝕／膨脹／開／閉：獨立比較
```

先預測：陰影會影響哪一種門檻？椒鹽雜訊適合先比較哪種濾波？形態學核可能刪掉哪些真實結構？

### 二、完整程式

存成 **`lesson06_method_lab.py`**。程式不依賴共用檔案，不指定照片時使用自製陰影圖，指定檔案時處理實際解碼內容。

```python
from pathlib import Path
from tempfile import mkdtemp
import json
import sys
import cv2
import numpy as np

BASE_DIR = Path(__file__).resolve().parent


def make_demo():
    gray = np.full((240, 400), 235, dtype=np.uint8)
    cv2.rectangle(gray, (35, 35), (130, 95), 35, -1)
    cv2.circle(gray, (205, 65), 28, 40, 2)
    cv2.putText(gray, "ABC", (270, 80), cv2.FONT_HERSHEY_SIMPLEX, 0.8, 30, 2)
    for y in [140, 150, 160, 170, 180]:
        gray[y:y + 1, 30:370] = 30
    cv2.circle(gray, (220, 205), 2, 20, -1)
    illumination = np.linspace(0.45, 1.0, gray.shape[1])[None, :]
    return np.rint(gray.astype(np.float32) * illumination).astype(np.uint8)


def read_gray(path):
    raw = Path(path).read_bytes()
    if not raw:
        raise ValueError("來源檔案是空的")
    bgr = cv2.imdecode(np.frombuffer(raw, dtype=np.uint8), cv2.IMREAD_COLOR)
    if bgr is None:
        raise ValueError("來源不是可解碼的圖片")
    return cv2.cvtColor(bgr, cv2.COLOR_BGR2GRAY)


def write_png(path, image):
    ok, buffer = cv2.imencode(".png", image)
    if not ok:
        raise ValueError("PNG 編碼失敗")
    with Path(path).open("xb") as file:
        file.write(buffer.tobytes())


def mse(reference, result):
    difference = reference.astype(np.float32) - result.astype(np.float32)
    return float(np.mean(difference ** 2))


def run_experiment(gray):
    rng = np.random.default_rng(42)
    gaussian_noise = np.rint(gray.astype(np.float32) + rng.normal(0, 12, gray.shape)).clip(0, 255).astype(np.uint8)
    salt_pepper = gray.copy()
    indices = rng.choice(gray.size, round(gray.size * 0.04), replace=False)
    half = len(indices) // 2
    salt_pepper.flat[indices[:half]] = 0
    salt_pepper.flat[indices[half:]] = 255
    kernel = np.array([[1, 2, 1], [2, 4, 2], [1, 2, 1]], dtype=np.float32) / 16

    stages = {
        "01_original": gray.copy(),
        "02_bright": np.clip(gray.astype(np.float32) + 40, 0, 255).astype(np.uint8),
        "03_contrast": np.rint(1.5 * (gray.astype(np.float32) - 128) + 128).clip(0, 255).astype(np.uint8),
        "04_equalized": cv2.equalizeHist(gray),
        "05_clahe": cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8)).apply(gray),
        "06_gaussian_noise": gaussian_noise,
        "07_salt_pepper": salt_pepper,
        "08_mean": cv2.blur(gaussian_noise, (3, 3)),
        "09_weighted": cv2.filter2D(gaussian_noise, -1, kernel),
        "10_gaussian_filter": cv2.GaussianBlur(gaussian_noise, (3, 3), sigmaX=0),
        "11_median": cv2.medianBlur(salt_pepper, 3),
    }

    # 門檻比較使用同一份輸入，不混入人工雜訊分支。
    work = cv2.GaussianBlur(gray, (3, 3), sigmaX=0)
    stages["12_threshold_input"] = work
    _, stages["13_fixed"] = cv2.threshold(work, 160, 255, cv2.THRESH_BINARY)
    otsu, stages["14_otsu"] = cv2.threshold(work, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)
    stages["15_adaptive_mean"] = cv2.adaptiveThreshold(
        work, 255, cv2.ADAPTIVE_THRESH_MEAN_C, cv2.THRESH_BINARY, 31, 10)
    stages["16_adaptive_gaussian"] = cv2.adaptiveThreshold(
        work, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 31, 10)
    foreground = 255 - stages["16_adaptive_gaussian"]
    stages["17_foreground"] = foreground
    element = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
    stages["18_erode"] = cv2.erode(foreground, element)
    stages["19_dilate"] = cv2.dilate(foreground, element)
    stages["20_open"] = cv2.morphologyEx(foreground, cv2.MORPH_OPEN, element)
    stages["21_close"] = cv2.morphologyEx(foreground, cv2.MORPH_CLOSE, element)

    metrics = {
        "otsu_threshold": float(otsu),
        "gaussian_noise_mse": mse(gray, gaussian_noise),
        "gaussian_filter_mse": mse(gray, stages["10_gaussian_filter"]),
        "salt_pepper_mse": mse(gray, salt_pepper),
        "median_mse": mse(gray, stages["11_median"]),
        "foreground_pixels": int(np.count_nonzero(foreground)),
        "opened_foreground_pixels": int(np.count_nonzero(stages["20_open"])),
    }
    return stages, metrics


def main():
    if len(sys.argv) > 1:
        source = Path(sys.argv[1]).expanduser().resolve()
        gray = read_gray(source)
        source_name = source.name
    else:
        gray = make_demo()
        source_name = "generated_shadow"
    if min(gray.shape) < 31:
        raise ValueError("此實驗使用 31 像素鄰域，請使用至少 31 × 31 的圖片")
    before = gray.copy()
    stages, metrics = run_experiment(gray)

    root = BASE_DIR / "output" / "lesson06"
    root.mkdir(parents=True, exist_ok=True)
    run = Path(mkdtemp(prefix="experiment_", dir=str(root)))
    for name, image in stages.items():
        write_png(run / f"{name}.png", image)
    comparison = np.concatenate([gray, stages["13_fixed"], stages["14_otsu"],
                                 stages["16_adaptive_gaussian"]], axis=1)
    write_png(run / "threshold_comparison.png", comparison)
    report = {
        "source": source_name,
        "shape": list(gray.shape),
        "parameters": {"seed": 42, "noise_sigma": 12, "salt_pepper_amount": 0.04,
                       "filter_size": 3, "block_size": 31, "C": 10, "morph_size": 3},
        "metrics": metrics,
        "original_unchanged": bool(np.array_equal(gray, before)),
    }
    (run / "report.json").write_text(
        json.dumps(report, ensure_ascii=False, indent=2, allow_nan=False), encoding="utf-8")
    print(json.dumps(report, ensure_ascii=False, indent=2))
    print("輸出位置：", run)


if __name__ == "__main__":
    main()
```

### 三、如何讀取結果

執行 `python lesson06_method_lab.py`。輸出包含 21 張分階段圖片、1 張門檻比較圖與 `report.json`。處理自己的照片時執行 `python lesson06_method_lab.py "照片路徑.png"`。

比較圖從左到右是原灰階、固定門檻、Otsu、自適應高斯門檻。所有二值圖都應只包含 `0` 與 `255`，`original_unchanged` 應為 `true`。

人工加雜訊分支的 MSE 是相對於加入雜訊前的像素誤差，不是辨識準確率。即使 MSE 降低，仍要檢查細線與小點；真實照片本來的模糊或雜訊也不會因這個比較就有了真實答案。

## 常見問題

**二值圖全白或全黑：**檢查灰階範圍、是否誤用了反相、影像是否為 `uint8`，以及門檻是否合理。

**自適應門檻報錯：**確認是二維 `uint8`，`blockSize` 是大於 1 的奇數。

**文字被侵蝕得更粗：**檢查文字究竟是白色前景還是黑色背景。運算對像素集合生效，不知道人眼要保留什麼。

**結果平滑但細節消失：**減小核，重新檢查是否真的需要濾波，而不是繼續加強二值化。

## 章末自我檢查

解釋亮度、對比、去雜訊與二值化的差異。說明 Otsu 與局部門檻如何選擇比較值，並手算一個 3 × 3 平均與中位數。最後以白色前景說明四種形態學的順序與風險。

## 與後續專題的連結

樂譜中的附點、符桿與五線都是可能被平滑或形態學破壞的內容。後續整合時保留灰階輸入與二值化預覽，是否改善 OMR 要用實際辨識結果比較，不能只看圖片更黑白分明。
