# ScoreSense 逐步專題講義 v2

這是重新設計後的教學版。

和上一版最大的差別：**不再從完整專案執行開始。**

建議使用順序：

```text
00 課程總目錄
↓
01 → 26 依序上課
↓
A 教師版只給老師看
↓
reference_project 最後才拿來核對
```

學生只需具備基本程式概念，不假設已熟悉 Python、影像處理、XML、OMR、API 或前端。

教材每章盡量採用：

```text
問題
→ 觀念
→ 最小程式
→ 預測
→ 執行
→ 修改
→ 專題積木
→ 驗收
```

`materials/` 已附最小 MusicXML 與三張影像練習素材。

`reference_project/` 是最後完整 MVP 的參考版本，不建議前期讓學生直接複製。
