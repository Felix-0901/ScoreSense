# 第 7 章｜傾斜偵測與旋轉校正

手機拍攝時，樂譜很容易不是完全水平。對人眼來說可能只歪一點，但辨識工具往往對版面方向更敏感。

這一章要完成兩件事：**估計傾斜角度**，以及**把圖片旋回來**。

## 學習目標

- 理解為什麼需要先建立前景遮罩。
- 使用 Otsu 產生反相二值圖。
- 使用 `np.where` 取得前景座標。
- 使用 `cv2.minAreaRect` 估計方向。
- 使用旋轉矩陣與 `warpAffine` 校正。

## 單元一｜為什麼先反相？

樂譜通常：

```text
背景白色 255
符號黑色 0
```

但如果我們想找「有內容的像素」，讓前景變成白色比較方便：

```python
_, binary_inv = cv2.threshold(
    gray,
    0,
    255,
    cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU,
)
```

現在符號與五線譜接近 255，背景接近 0。

---

## 單元二｜取得所有前景座標

```python
import numpy as np

coords = np.column_stack(np.where(binary_inv > 0))
print(coords.shape)
```

`np.where()` 對二維陣列會先給 `y` 再給 `x`。

這些點代表「圖片裡被視為前景的位置」。

---

## 單元三｜用最小外接旋轉矩形估方向

```python
angle = cv2.minAreaRect(coords.astype(np.float32))[-1]
print(angle)
```

OpenCV 回傳角度的定義可能和直覺不同，所以需要正規化。

```python
if angle < -45:
    angle = 90 + angle
elif angle > 45:
    angle = angle - 90
```

專案中另外限制：

```python
if abs(angle) > 15:
    angle = 0.0
```

原因是：如果估出非常誇張的角度，可能不是正常「輕微拍歪」，而是資料或估計出了問題。保守地不旋轉可能比錯轉 70 度好。

## 單元四｜旋轉圖片

```python
h, w = gray.shape[:2]
center = (w / 2.0, h / 2.0)

matrix = cv2.getRotationMatrix2D(
    center,
    angle,
    1.0,
)

rotated = cv2.warpAffine(
    gray,
    matrix,
    (w, h),
    flags=cv2.INTER_CUBIC,
    borderMode=cv2.BORDER_CONSTANT,
    borderValue=255,
)
```

### 參數理解

- `center`：繞哪個中心旋轉。
- `angle`：旋轉角度。
- `1.0`：不縮放。
- `(w, h)`：輸出尺寸。
- `borderValue=255`：旋轉後空白區補白色。

對樂譜來說，用黑色補邊通常不合理。

---

## 單元五｜先用已知角度驗證旋轉函式

不要一開始就把「估角度」與「旋轉」一起除錯。

先測：

```python
rotated = rotate_image(gray, 7)
```

確認方向與結果正確，再接自動估計。

這是一個重要除錯習慣：

```text
先確認子功能 A
再確認子功能 B
最後才接 A → B
```

## 綜合實作｜拆成兩個函式

```python
import cv2
import numpy as np


def estimate_skew(binary_inv):
    coords = np.column_stack(np.where(binary_inv > 0))

    if len(coords) < 100:
        return 0.0

    angle = cv2.minAreaRect(coords.astype(np.float32))[-1]

    if angle < -45:
        angle = 90 + angle
    elif angle > 45:
        angle = angle - 90

    if abs(angle) > 15:
        return 0.0

    return float(angle)


def rotate_image(image, angle):
    if abs(angle) < 0.1:
        return image

    h, w = image.shape[:2]
    center = (w / 2.0, h / 2.0)
    matrix = cv2.getRotationMatrix2D(center, angle, 1.0)

    return cv2.warpAffine(
        image,
        matrix,
        (w, h),
        flags=cv2.INTER_CUBIC,
        borderMode=cv2.BORDER_CONSTANT,
        borderValue=255,
    )
```
