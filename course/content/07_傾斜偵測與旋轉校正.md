# 第 7 章｜邊緣、傾斜偵測與旋轉校正

邊緣圖指出亮度變化，輪廓描述前景邊界，線段偵測找出直線候選。這些結果可以用來分析圖片結構，但不會自動告訴我們每顆音符是什麼。

本章先分別操作，再估計長線的方向，最後將圖片旋轉。沿用 **Python 3.11**、根目錄 `test.jpg` 與 OpenCV 視窗。每段程式都獨立執行，不需要共用函式檔。

方向估計適合有清楚、近水平平行長線的圖片。測試圖不是樂譜或找不到長線時，回報無法估計是合理結果，不代表應該猜一個角度。

## 學習目標

- 理解差分、Sobel、梯度與 Canny。
- 顯示輪廓、面積、外接框與霍夫線段。
- 分清楚 `(x, y)`、列欄索引與旋轉方向。
- 執行平移、旋轉、擴大畫布與透視轉換。
- 將灰階、邊緣、線段與旋轉串成可觀察的流程。

## 單元一｜亮度差分

相鄰像素的差值可表示亮度變化。從 20 到 200 是 +180，從 200 到 20 是 −180。正負號保存方向，不是雜訊。

### 完整範例

```python
import numpy as np

row = np.array([20, 20, 200, 200, 20], dtype=np.uint8)
difference = np.diff(row.astype(np.int16))
print("原亮度：", row)
print("差分：", difference)
```

`np.diff()` 逐項計算「下一個減上一個」，因此 n 個數字得到 n−1 個差值。先轉成有號整數，避免負值被 `uint8` 回繞。

這是數值手算範例，下一單元才把亮度變化顯示成影像。雜點也會造成大差值，不能只看差分大就說是物體邊界。

## 單元二｜Sobel 的 x 與 y 梯度

3 × 3 Sobel 核會把鄰域加權後求差。x 梯度對左右亮度變化敏感，通常凸顯垂直邊界；y 梯度對上下變化敏感，通常凸顯水平邊界。

```text
x 方向核：          y 方向核：
-1  0  1            -1 -2 -1
-2  0  2             0  0  0
-1  0  1             1  2  1
```

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)
gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)
x_view = cv2.convertScaleAbs(gx, alpha=0.25)
y_view = cv2.convertScaleAbs(gy, alpha=0.25)

cv2.imshow("Gray", gray)
cv2.imshow("Sobel X", x_view)
cv2.imshow("Sobel Y", y_view)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新參數／函式 | 意義 |
| --- | --- |
| `CV_32F` | 用 32 位元浮點保存可能超過 255 或小於 0 的梯度 |
| `1, 0` | 對 x 取一階導數，不對 y 求導 |
| `0, 1` | 對 y 取一階導數，不對 x 求導 |
| `ksize=3` | 使用 3 × 3 核 |
| `convertScaleAbs(..., alpha=0.25)` | 縮放、取絕對值並轉成 8 位元顯示圖 |

對本例 3 × 3 Sobel，除以 4 有助於顯示；不是所有核都固定用這個倍率。原本的 `gx`、`gy` 仍保留正負號，顯示副本才取絕對值。

**手算：**若三列都是 `[10, 10, 110]`，中心的 x 梯度為 400，y 梯度為 0。結果大於 255，正是要保留浮點深度的原因。

## 單元三｜梯度大小與方向

同時有 x、y 變化時，梯度大小為 `sqrt(gx² + gy²)`；方向用 `atan2(gy, gx)`。梯度方向通常垂直於邊界方向。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)
gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)
magnitude = np.hypot(gx, gy)
direction = np.degrees(np.arctan2(gy, gx))
view_image = cv2.normalize(magnitude, None, 0, 255, cv2.NORM_MINMAX).astype(np.uint8)
print("最大梯度：", magnitude.max())

cv2.imshow("Gray", gray)
cv2.imshow("Gradient magnitude", view_image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新寫法 | 用途 |
| --- | --- |
| `np.hypot(gx, gy)` | 計算平方和的平方根 |
| `np.arctan2(y, x)` | 根據兩個分量計算角度，可處理不同象限 |
| `np.degrees()` | 弧度轉角度 |
| `cv2.normalize(..., 0, 255, NORM_MINMAX)` | 將本張圖數值範圍映射成顯示範圍 |

梯度為零的位置沒有有意義的方向。不同圖片各自正規化後的白色，不代表原始梯度一樣大。

## 單元四｜Canny 邊緣

Canny 使用梯度、局部極大值抑制與雙門檻追蹤，產生較細的邊緣。先明確做高斯平滑，再進行偵測。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
smooth = cv2.GaussianBlur(gray, (3, 3), sigmaX=0)
edges = cv2.Canny(smooth, 50, 150, apertureSize=3, L2gradient=True)

cv2.imshow("Gray", gray)
cv2.imshow("Canny edges", edges)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新參數 | 意義 |
| --- | --- |
| `50`、`150` | 低、高梯度門檻，不是原始像素的灰階門檻 |
| `apertureSize=3` | 梯度計算所用 Sobel 大小 |
| `L2gradient=True` | 使用歐氏梯度大小 |

經抑制後的強邊緣保留，較弱候選要沿符合條件的連通路徑接到強邊緣才保留。高門檻不代表真實物體一定存在。

**練習：**比較 `(30, 90)`、`(50, 150)`、`(100, 200)`。觀察邊緣增加時是否也帶入背景紋理。

Canny 雖是黑白圖，標記的是邊界；二值化遮罩通常表示整塊前景，兩者不能直接當成相同資料。

## 單元五｜尋找並畫出輪廓

輪廓是前景邊界的一串點。本例先用反相 Otsu 把深色內容變成白色前景，再找外輪廓。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
contours, hierarchy = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
marked = image.copy()
cv2.drawContours(marked, contours, -1, (0, 0, 255), 2)
print("外輪廓數：", len(contours))

cv2.imshow("Foreground", binary)
cv2.imshow("Contours", marked)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新寫法 | 意義 |
| --- | --- |
| `findContours()` | 回傳輪廓集合與階層關係 |
| `RETR_EXTERNAL` | 只找最外層輪廓 |
| `CHAIN_APPROX_SIMPLE` | 壓縮直線上的冗餘輪廓點 |
| `hierarchy` | 輪廓的父子／前後關係；這個範例暫不使用 |
| `drawContours(..., -1, ...)` | `-1` 表示畫全部輪廓，不是填滿；最後的 2 才是線粗 |

| 其他常見選項 | 用途 |
| --- | --- |
| `RETR_TREE` | 保留完整巢狀階層 |
| `CHAIN_APPROX_NONE` | 保存所有輪廓邊界點 |

**觀察：**五線可能與音符連成同一區域，因此輪廓數不等於音符數。這裡只找形狀，沒有音樂符號辨識。

## 單元六｜輪廓面積與外接矩形

用面積先排除很小的候選，再畫外接矩形。這只能篩選大小，不能證明候選是音符或紙張。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
marked = image.copy()
for contour in contours:
    area = cv2.contourArea(contour)
    if area < 50:
        continue
    x, y, width, height = cv2.boundingRect(contour)
    cv2.rectangle(marked, (x, y), (x + width - 1, y + height - 1), (0, 255, 0), 2)
    print("面積、外接框：", area, x, y, width, height)

cv2.imshow("Original", image)
cv2.imshow("Bounding boxes", marked)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`contourArea()` 是幾何面積，不保證等於白色像素數。`boundingRect()` 回傳 `(左上角 x, 左上角 y, 寬, 高)`，不是右下角座標。

門檻 50 的單位是像素座標形成的面積；圖片縮放後，這個值也要重新評估。不要將它當成辨識信心分數。

## 單元七｜前景座標與最小外接旋轉矩形

NumPy 回傳列 y、欄 x，OpenCV 幾何需要 x、y。先把兩者分清楚，再找能包住前景點的最小面積矩形。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
ys, xs = np.where(binary > 0)
points = np.column_stack((xs, ys)).astype(np.float32)
marked = image.copy()
if len(points) >= 3:
    rectangle = cv2.minAreaRect(points)
    box = cv2.boxPoints(rectangle)
    box_int = np.rint(box).astype(np.int32)
    cv2.drawContours(marked, [box_int], 0, (0, 0, 255), 2)
    print("中心、寬高、OpenCV 角度：", rectangle)
else:
    print("前景點不足")

cv2.imshow("Foreground", binary)
cv2.imshow("Minimum area box", marked)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新寫法 | 意義 |
| --- | --- |
| `np.where(binary > 0)` | 對二維條件回傳 y 索引與 x 索引 |
| `column_stack((xs, ys))` | 組成每列 `(x, y)` 的點陣列 |
| `minAreaRect(points)` | 回傳中心、寬高及矩形角度資訊 |
| `boxPoints(rectangle)` | 取得四個角點 |
| `astype(np.int32)` | 轉為繪圖使用的整數座標 |

不能直接把 `column_stack(np.where(...))` 產生的 `(y, x)` 當作 `(x, y)`。也不能把 `minAreaRect()` 的原始角度一律理解為「應旋轉的角度」，它跟矩形選邊與寬高定義有關。

遠處雜點、頁框、標題與直式版面都會影響整體矩形。本例先觀察外框，不自動拿回傳角度去旋轉。

## 單元八｜霍夫線段偵測

霍夫線段偵測從邊緣中尋找直線候選。對五線譜，可先看是否真的找到多條長線。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

height, width = gray.shape
smooth = cv2.GaussianBlur(gray, (3, 3), 0)
edges = cv2.Canny(smooth, 50, 150, L2gradient=True)
lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=40,
                        minLineLength=max(30, width // 3), maxLineGap=10)
marked = image.copy()
if lines is None:
    print("沒有找到符合條件的線段")
else:
    for line in lines:
        x1, y1, x2, y2 = line[0]
        cv2.line(marked, (x1, y1), (x2, y2), (0, 0, 255), 2)
    print("線段數：", len(lines))

cv2.imshow("Edges", edges)
cv2.imshow("Detected lines", marked)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新參數／寫法 | 意義 |
| --- | --- |
| `1` | 距離解析度，這裡為 1 像素 |
| `np.pi / 180` | 角度解析度為 1 度，用弧度表示 |
| `threshold=40` | 累積投票門檻，不是灰階門檻 |
| `minLineLength` | 最短線段長度 |
| `maxLineGap` | 同方向線段允許接起的最大間隙 |
| `line[0]` | OpenCV 回傳每筆中的四個端點數字 |

**練習：**只改最短長度，觀察紙張邊界、桌面紋理、五線是否被一併找到。找出線段不代表已知道線段的用途。

## 單元九｜用線段估計傾斜

先計算 `dx=x2−x1`、`dy=y2−y1`，再用 `atan2(dy, dx)` 得到線方向。圖片 y 向下，所以往右下傾斜的線有正角度。

把等價的反向線正規化成 `[-90, 90)`，只保留接近水平、絕對角度不超過 15 度的候選，再檢查方向與高度分布。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

height, width = gray.shape
smooth = cv2.GaussianBlur(gray, (3, 3), 0)
edges = cv2.Canny(smooth, 50, 150, L2gradient=True)
lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=40,
                        minLineLength=max(30, width // 3), maxLineGap=10)
angles = []
rows = []
if lines is not None:
    for line in lines:
        x1, y1, x2, y2 = line[0]
        dx = float(x2 - x1)
        dy = float(y2 - y1)
        angle = np.degrees(np.arctan2(dy, dx))
        angle = (angle + 90) % 180 - 90
        if dx != 0 and abs(angle) <= 15:
            angles.append(float(angle))
            rows.append(float(y1) + (width / 2 - float(x1)) * dy / dx)

estimated = None
reason = "候選線段不足"
if len(angles) >= 4:
    values = np.array(angles)
    median = float(np.median(values))
    consistent = np.abs(values - median) <= 2
    positions = sorted(np.array(rows)[consistent].tolist())
    row_count = 0
    last_row = None
    for row in positions:
        if last_row is None or row - last_row > 4:
            row_count += 1
            last_row = row
    if consistent.mean() >= 0.75 and consistent.sum() >= 4 and row_count >= 3:
        estimated = float(np.median(values[consistent]))
        reason = "取得方向相近且分布於不同高度的長線"
    else:
        reason = "線段方向或高度分布不足"
print("估計線方向：", estimated)
print("原因：", reason)

cv2.imshow("Gray", gray)
cv2.imshow("Edges", edges)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 逐步解讀新增部分

`(angle + 90) % 180 - 90` 把反向但同一直線的角度放在同一範圍。`np.median()` 取中位數；`np.abs(values - median) <= 2` 選出和中位數相差不超過 2 度的線。

`rows` 計算各線在圖片中央 x 處的 y 位置，讓不同端點位置的線仍可比較高度。至少三組高度是避免只靠同一條粗線的多個邊緣猜角度，不是完成五線譜辨識。

`np.array(rows)[consistent]` 選出方向相近的高度，`.tolist()` 轉回 Python 串列，`sorted()` 排序。`consistent.sum()` 計算相近線數，`consistent.mean()` 計算其比例；`last_row` 保存上一組高度的起點。

至少 4 條候選、75% 方向相近、高度差 4 像素，都是本例的保守設定，需要根據影像大小與內容評估，不能保證擋住所有錯誤候選。

`estimated=None` 表示無法可信地估計，不等於 0 度。0 度才表示取得候選後，估計接近水平。

## 單元十｜固定角度旋轉

先人工指定角度，確認旋轉方向，再串接自動估計。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
height, width = gray.shape
center = ((width - 1) / 2, (height - 1) / 2)
angle = 7.0
matrix = cv2.getRotationMatrix2D(center, angle, 1.0)
rotated = cv2.warpAffine(gray, matrix, (width, height),
                         flags=cv2.INTER_LINEAR,
                         borderMode=cv2.BORDER_CONSTANT, borderValue=255)

cv2.imshow("Gray", gray)
cv2.imshow("Rotate +7 degrees", rotated)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新參數／函式 | 意義 |
| --- | --- |
| `getRotationMatrix2D(center, angle, scale)` | 建立 2 × 3 旋轉矩陣 |
| `angle=7.0` | 正角度逆時針，負角度順時針，單位為度 |
| `scale=1.0` | 不額外縮放 |
| `warpAffine()` | 依矩陣變換像素位置 |
| `(width, height)` | 指定輸出畫布寬高 |
| `borderValue=255` | 單通道空白處補白；彩圖應使用三值白色 |

輸出畫布不擴大，四角內容可能被切掉。這不是資料讀取失敗，而是旋轉後超出畫布。

若量到線的圖像座標方向為 +7 度，呼叫正 +7 度逆時針旋轉可把它拉回水平。不要再不加思考地加一個負號。由本例人工逆時針轉 +7 度製造的線，量到的方向反而應接近 −7 度。

## 單元十一｜擴大畫布旋轉

為了容納旋轉後的四角，先計算新的外框寬高，再調整矩陣平移，使圖片仍位於新畫布中央。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

angle = 7.0
height, width = gray.shape
center = ((width - 1) / 2, (height - 1) / 2)
matrix = cv2.getRotationMatrix2D(center, angle, 1.0)
cosine = abs(matrix[0, 0])
sine = abs(matrix[0, 1])
new_width = int(np.ceil(width * cosine + height * sine))
new_height = int(np.ceil(height * cosine + width * sine))
matrix[0, 2] += (new_width - 1) / 2 - center[0]
matrix[1, 2] += (new_height - 1) / 2 - center[1]
rotated = cv2.warpAffine(gray, matrix, (new_width, new_height),
                         flags=cv2.INTER_LINEAR,
                         borderMode=cv2.BORDER_CONSTANT, borderValue=255)

cv2.imshow("Gray", gray)
cv2.imshow("Expanded rotation", rotated)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`matrix[0,0]`、`matrix[0,1]` 在縮放為 1 時對應餘弦與正弦分量。外框寬為 `w×|cos| + h×|sin|`，高為 `h×|cos| + w×|sin|`；`np.ceil()` 向上取整，避免少留一部分。

矩陣最後一欄控制平移。兩個 `+=` 將原中心移到新畫布中心。

**觀察：**四角是否完整？畫布是否變大？細線因插值稍微變淡，和四角被裁掉是兩個不同問題。

## 單元十三｜已知四角的透視轉換

紙張被斜拍成梯形時，只旋轉不能把四邊拉成矩形。透視轉換用四對對應點建立投影關係。

本例四點只是畫面中的示範座標，**沒有自動找紙張**。請看紅框，再把座標換成自己圖片的實際紙張四角，順序固定為左上、右上、右下、左下，不能交叉。

### 完整範例

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

import numpy as np

height, width = image.shape[:2]
source_points = np.float32([
    [0.15 * width, 0.10 * height],
    [0.85 * width, 0.15 * height],
    [0.90 * width, 0.90 * height],
    [0.10 * width, 0.85 * height],
])
destination_points = np.float32([[0, 0], [399, 0], [399, 599], [0, 599]])
matrix = cv2.getPerspectiveTransform(source_points, destination_points)
rectified = cv2.warpPerspective(image, matrix, (400, 600),
                                 borderValue=(255, 255, 255))
marked = image.copy()
cv2.polylines(marked, [np.rint(source_points).astype(np.int32)], True, (0, 0, 255), 2)

cv2.imshow("Selected quadrilateral", marked)
cv2.imshow("Perspective result", rectified)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

| 新函式／參數 | 意義 |
| --- | --- |
| `getPerspectiveTransform(src, dst)` | 從四對點計算 3 × 3 透視矩陣 |
| `warpPerspective(..., (400, 600))` | 將四邊形映射到指定寬高 |
| `polylines(..., True, ...)` | 畫多段線，`True` 表示首尾閉合 |

四點需要互相分開、不能共線或交叉。目標 400 × 600 是示範比例；不符合實際紙張比例時會拉伸，不能據此宣稱恢復了真實尺寸。

**練習：**更換實際四角，觀察文字是否拉正。曲面的書頁彎曲也不一定能靠單一透視矩陣解決。

## 單元十四｜輪廓周長與多邊形近似：取得紙張四角候選
「輪廓可能有幾十個點，但我們要的是紙張的四個轉角。先計算一圈有多長，再允許少量偏差，把輪廓簡化成多邊形。若簡化後有四個角，就留下來觀察。」

`arcLength()` 計算曲線長度；`approxPolyDP()` 根據 epsilon 控制近似曲線和原輪廓的距離。它沒有『保證回傳四點』這個選項；點數必須自己檢查。

### 完整範例

```python
import cv2
import numpy as np

# 請將 test6.jpg 放在執行程式時的工作目錄。
# 圖片必須是桌上白紙，不是隨意的風景或只有文字的截圖。
image = cv2.imread("test6.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test6.jpg，請檢查工作目錄、檔名與圖片內容")

# 已教過：BGR 轉灰階，然後以 Otsu 自動選取全圖門檻。
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# 找黑字時用 INV；現在要找亮色的整張白紙，所以刻意不使用 INV。
# 白紙是 255 前景，較暗桌面是 0 背景。
threshold_value, binary = cv2.threshold(
    gray, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU
)
print("Otsu 門檻：", threshold_value)

# _ 代表不使用 hierarchy；本課先不分析紙張內部的洞或文字階層。
contours, _ = cv2.findContours(
    binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE
)

# height、width 的順序來自 shape；OpenCV 畫點時則使用 (x,y)。
height, width = image.shape[:2]
min_area = height * width * 0.15  # 候選至少占 15%，是教學起始設定。
best_polygon = None             # None 代表還沒有找到，不能假裝是 0 度或空圖片。
best_area = 0.0

for contour in contours:
    area = cv2.contourArea(contour)
    if area < min_area:
        continue                # 這一個太小，接著看下一個輪廓。

    # 沿用 boundingRect；照片邊界不是紙張邊界。
    # 本次約定紙張周圍留桌面，因此碰到照片邊緣的候選先跳過。
    x, y, w, h = cv2.boundingRect(contour)
    if x <= 0 or y <= 0 or x + w >= width or y + h >= height:
        continue

    # 【新增】arcLength：周長；True 把最後一點接回第一點。
    perimeter = cv2.arcLength(contour, True)
    if perimeter <= 0:
        continue

    # 【新增】epsilon 是容許的幾何距離偏差，不是面積比例或信心分數。
    # 周長 1000 像素，0.02 倍就是 20 像素的近似容許偏差。
    # 小一點通常保留更多細節；大一點可能把本來的角也簡化掉。
    epsilon = 0.02 * perimeter
    approx = cv2.approxPolyDP(contour, epsilon, True)
    print("面積、周長、近似頂點數：", area, perimeter, len(approx))

    # approx 常是 (點數,1,2)，len(approx) 得到的是點數。
    if len(approx) != 4:
        continue

    # 【新增】凸性檢查：平整紙張的外框不應往內凹。
    # True 只代表凸形；不是證明這個物體就是白紙。
    if not cv2.isContourConvex(approx) or cv2.contourArea(approx) <= 1:
        continue

    # 簡單選擇：在有效候選中保留最大的，沒有加入複雜評分。
    if area > best_area:
        best_area = area
        best_polygon = approx

# 用副本畫圖；None 時仍保留遮罩視窗，方便知道為什麼找不到。
marked = image.copy()
if best_polygon is None:
    print("沒有合格四邊形。先看 Binary 是否把紙與桌面分開。")
else:
    print("未排序四角：\n", best_polygon.reshape(4, 2))
    cv2.drawContours(marked, [best_polygon], -1, (0, 0, 255), 3)
    for x, y in best_polygon.reshape(4, 2):
        # circle 最後的 -1 是填滿；drawContours 的第三個 -1 才是畫全部。
        cv2.circle(marked, (int(x), int(y)), 6, (0, 255, 0), -1)

cv2.imshow("Original", image)
cv2.imshow("Binary - paper foreground", binary)
cv2.imshow("Paper corner candidates", marked)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 第一次出現的寫法

| 寫法 | 口頭解釋 |
| --- | --- |
| `arcLength(contour, True)` | 計算封閉輪廓周長，True 讓首尾相接 |
| `0.02 * perimeter` | 容許距離隨輪廓大小改變，不是只留下 2% 點 |
| `approxPolyDP(..., True)` | 在誤差限制內用較少頂點近似封閉輪廓 |
| `len(approx) == 4` | 得到四個頂點才進下一步，不等於 A4 分類 |
| `isContourConvex(approx)` | 確認外框沒有向內凹；仍不能證明是紙張 |
| `best_polygon = None` | 尚未找到候選，不能拿 None 去做透視 |
| `reshape(4,2)` | 改成四列，每列 x、y；沒有改變幾何位置 |
| `[best_polygon]` | drawContours 需要輪廓集合，所以將單一輪廓包成集合 |

### 預期與檢查

先看 Binary：白色應是紙張，不是整個桌面。再看四角點是否落在紙張外角，不能只看終端機顯示「4」。
把 epsilon 係數一次改成 0.005、0.02、0.05，比較頂點數；每次只改一個數值。15% 面積門檻也只是起始條件。

**自我檢查：**學生能解釋哪個變數是一個輪廓、哪個是全部輪廓，以及為什麼四點仍只是候選。

## 單元十五｜四角排序：先做純座標練習
「透視轉換只認第 0 點要搬到哪裡，不知道第 0 點是不是左上。先把四個點排成一致順序，之後才能一一對應。」

本課使用簡單方法：先按 y 分成上、下兩組，再在各組按 x 分左右。
不是另外加入角度、極座標或任意旋轉排序。使用條件不成立時，先調整拍照方向，不硬猜角落。

### 完整範例：座標示意

```python
# 四角排序單獨練習：先不要把找紙張與排序一起除錯。
import cv2
import numpy as np

# 這四點是「座標示意」，不是從照片自動偵測出的結果。
# 故意打亂成 TR、BL、TL、BR；可再自己換順序。
points = np.float32([
    [700, 130],
    [120, 640],
    [160, 100],
    [740, 660],
])
print("排序前：\n", points)

# points[:,1] 是全部 y；argsort 回傳 y 由小到大的索引。
# 不能直接 np.sort(points,axis=0)，那會把 x 和 y 分開排序。
y_indices = np.argsort(points[:, 1])
by_y = points[y_indices]
top = by_y[:2]
bottom = by_y[2:]

# 每組再按 x 左右排列。
top = top[np.argsort(top[:, 0])]
bottom = bottom[np.argsort(bottom[:, 0])]
tl, tr = top
bl, br = bottom
ordered = np.array([tl, tr, br, bl], dtype=np.float32)
print("TL、TR、BR、BL：\n", ordered)

# 用已學過的 full、polylines、circle、putText 畫一張純座標示意圖。
# 畫布大小用 (高,寬,通道)，讓四個指定座標都落在裡面。
canvas = np.full((760, 880, 3), 245, dtype=np.uint8)
line_points = ordered.astype(np.int32).reshape(4, 1, 2)
cv2.polylines(canvas, [line_points], True, (0, 0, 255), 3)
for label, point in zip(["TL", "TR", "BR", "BL"], ordered):
    x, y = point
    position = (int(x), int(y))
    cv2.circle(canvas, position, 7, (0, 180, 0), -1)
    cv2.putText(canvas, label, (int(x)+10, int(y)-10),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0,0,0), 2)

# 圖上標籤要依順時針走 TL -> TR -> BR -> BL。
cv2.imshow("Corner order - coordinate demo", canvas)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 新寫法拆開解釋

| 寫法 | 意義 |
| --- | --- |
| `np.float32([...])` | 讓點陣列使用 32 位元浮點，後面可給透視函式 |
| `points[:,1]` | 每列都取第 1 欄，也就是 y |
| `np.argsort(values)` | 回傳排序後應使用的原本索引  |
| `points[y_indices]` | 依索引重新排列整個點；x、y 保持同一組 |
| `by_y[:2]`、`by_y[2:]` | 分成較上兩點、較下兩點 |
| `tl,tr = top` | 把兩列分別交給兩個變數 |
| `[tl,tr,br,bl]` | 下方改由右向左，形成不交叉的外框順序 |

本例應印出：`TL=(160,100)`、`TR=(700,130)`、`BR=(740,660)`、`BL=(120,640)`。
讓學生先打亂四點的輸入順序，再看結果是否維持一致。這只能證明此組符合假設的點排序成功，不是任意拍攝角度都正確。

**自我檢查：**學生能說明陣列索引 [y,x] 與幾何座標 (x,y) 的差別，並指出正確 TL/TR/BR/BL。

## 單元十六｜複習：已知四角時如何透視轉換
這部分複習單元十三已知四角的透視轉換。
`getPerspectiveTransform()` 算規則；`warpPerspective()` 才依規則生成新圖。來源與目標第 i 點要一一對應。

### 完整範例

```python
import cv2
import numpy as np

# 請將 test6.jpg 放在執行程式時的工作目錄。
# 圖片必須是桌上白紙，不是隨意的風景或只有文字的截圖。
image = cv2.imread("test6.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test6.jpg，請檢查工作目錄、檔名與圖片內容")

# 這段沿用原講義第 7 章「已知四角」的示範座標。
# 它不會自動找紙張！請先看紅框，再換成自己照片真正的四角。
height, width = image.shape[:2]
source_points = np.float32([
    [0.15 * width, 0.10 * height],  # TL
    [0.85 * width, 0.15 * height],  # TR
    [0.90 * width, 0.90 * height],  # BR
    [0.10 * width, 0.85 * height],  # BL
])

# 目標是寬 400、高 600 的示範矩形。
# 右側座標 399、下側座標 599，因為座標從 0 開始。
# 400×600 不是 A4 的真實比例，也不是自動恢復紙張尺寸。
destination_points = np.float32([
    [0, 0], [399, 0], [399, 599], [0, 599]
])

# 來源第 i 點對應目標第 i 點，因此順序必須一致。
# 此函式只回傳轉換規則，還沒有改變 image。
matrix = cv2.getPerspectiveTransform(source_points, destination_points)
print("透視矩陣形狀：", matrix.shape)
print(matrix)

# warpPerspective 才依矩陣產生新圖片；尺寸參數是 (寬,高)。
rectified = cv2.warpPerspective(
    image, matrix, (400, 600),
    flags=cv2.INTER_LINEAR,
    borderMode=cv2.BORDER_CONSTANT,
    borderValue=(255,255,255),
)

# 額外的框只畫在 marked，不讓它進入校正圖片。
marked = image.copy()
draw_points = np.rint(source_points).astype(np.int32)
cv2.polylines(marked, [draw_points], True, (0,0,255), 2)
cv2.imshow("Selected quadrilateral - check red frame", marked)
cv2.imshow("Perspective result", rectified)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 這裡必須說清楚

紅框的座標是示範用比例，不是自動偵測。如果學生照片中的紙張不在紅框位置，轉出來不正確不是 OpenCV 壞掉。
第一次可直接改為實際讀到的四個角點；確認四對對應正確後，再做自動串接。

| 名稱 | 解釋 |
| --- | --- |
| `source_points` | 原照片上的四個紙角，順序固定 |
| `destination_points` | 希望搬到的矩形四角，順序相同 |
| `matrix.shape == (3,3)` | 透視矩陣，不是已處理的圖片 |
| `(400,600)` | 畫布寬、高，與 shape 的高、寬不同 |
| `INTER_LINEAR` | 新位置通常不是整數像素，用雙線性插值取樣 |
| `borderValue=(255,255,255)` | 彩圖來源範圍外補白色 |

**自我檢查：**學生能區分計算矩陣與真正變換圖片兩個操作。

## 單元十七｜一條最小完整流程：自動四角 → 拉正
前面獨立方法都看懂後，才把它們接起來。這份先用直寫方式，不另外建立函式，方便觀察每個步驟。

輸出寬高由對邊的較長像素距離決定。本版只做簡單取樣尺寸估計，**不宣稱從投影邊長精確恢復紙張真實比例或 A4 尺寸**。

### 完整範例

```python
import cv2
import numpy as np

# 請將 test6.jpg 放在執行程式時的工作目錄。
# 圖片必須是桌上白紙，不是隨意的風景或只有文字的截圖。

if image is None:
    raise FileNotFoundError("讀不到 test6.jpg，請檢查工作目錄、檔名與圖片內容")

# 白紙是 255 前景，較暗桌面是 0 背景。
threshold_value, binary = cv2.threshold(
    gray, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU
)
print("Otsu 門檻：", threshold_value)

# _ 代表不使用 hierarchy；本課先不分析紙張內部的洞或文字階層。
contours, _ = cv2.findContours(
    binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE
)

# height、width 的順序來自 shape；OpenCV 畫點時則使用 (x,y)。

best_area = 0.0

for contour in contours:
    area = cv2.contourArea(contour)
    if area < min_area:
        continue                # 這一個太小，接著看下一個輪廓。

    # 沿用 boundingRect；照片邊界不是紙張邊界。
    # 本次約定紙張周圍留桌面，因此碰到照片邊緣的候選先跳過。
    x, y, w, h = cv2.boundingRect(contour)
    if x <= 0 or y <= 0 or x + w >= width or y + h >= height:
        continue

    perimeter = cv2.arcLength(contour, True)
    if perimeter <= 0:
        continue

    # 【新增】epsilon 是容許的幾何距離偏差，不是面積比例或信心分數。
    # 周長 1000 像素，0.02 倍就是 20 像素的近似容許偏差。
    # 小一點通常保留更多細節；大一點可能把本來的角也簡化掉。
    epsilon = 0.02 * perimeter
    approx = cv2.approxPolyDP(contour, epsilon, True)
    print("面積、周長、近似頂點數：", area, perimeter, len(approx))

    # approx 常是 (點數,1,2)，len(approx) 得到的是點數。
    if len(approx) != 4:
        continue

    # 【新增】凸性檢查：平整紙張的外框不應往內凹。
    # True 只代表凸形；不是證明這個物體就是白紙。
    if not cv2.isContourConvex(approx) or cv2.contourArea(approx) <= 1:
        continue

    # 簡單選擇：在有效候選中保留最大的，沒有加入複雜評分。
    if area > best_area:
        best_area = area
        best_polygon = approx

marked = image.copy()
scanned = None
if best_polygon is None:
    print("找不到紙張，沒有執行透視校正；請先查看 Binary。")
else:
    # 將輪廓角點整理成四列，每列 [x,y]，使用透視 API 所需的 float32。
    points = best_polygon.reshape(4, 2).astype(np.float32)

    # 【新增】argsort 回傳排序用的索引，不直接回傳排序後資料。
    # points[:,1] 取得四個 y；依這些索引排列整列，以保留 x,y 配對。
    y_indices = np.argsort(points[:, 1])
    by_y = points[y_indices]
    top = by_y[:2]                     # 前兩點：較靠上。
    bottom = by_y[2:]                  # 後兩點：較靠下。

    # 再對上下兩組，分別按 x 由小到大排列。
    top = top[np.argsort(top[:, 0])]
    bottom = bottom[np.argsort(bottom[:, 0])]
    tl, tr = top
    bl, br = bottom

    # 透視對應使用順時針：TL、TR、BR、BL，不是 TL、TR、BL、BR。
    source_points = np.array([tl, tr, br, bl], dtype=np.float32)

    # 【新增】norm 計算兩點距離：sqrt(dx**2 + dy**2)。
    # 取較長的對邊作為取樣尺寸，避免固定 400×600 硬拉成任意比例。
    width_top = np.linalg.norm(tr - tl)
    width_bottom = np.linalg.norm(br - bl)
    height_left = np.linalg.norm(bl - tl)
    height_right = np.linalg.norm(br - tr)

    # ceil 向上取整；加 1 是本例包含兩端像素位置的約定。
    # 這仍是照片投影尺寸估計，不是復原 A4 真實長寬或 DPI。
    output_width = max(2, int(np.ceil(max(width_top, width_bottom))) + 1)
    output_height = max(2, int(np.ceil(max(height_left, height_right))) + 1)
    destination_points = np.float32([
        [0, 0],
        [output_width - 1, 0],
        [output_width - 1, output_height - 1],
        [0, output_height - 1],
    ])

    # 已在 B 章教過：前者只算 3×3 規則，後者才改變影像。
    matrix = cv2.getPerspectiveTransform(source_points, destination_points)
    scanned = cv2.warpPerspective(
        image, matrix, (output_width, output_height),  # 注意是寬、高。
        flags=cv2.INTER_LINEAR,
        borderMode=cv2.BORDER_CONSTANT,
        borderValue=(255, 255, 255),                 # 彩圖要用三通道白色。
    )
    # 務必 warp 原始 image，不是 binary 或已經畫紅框的 marked。

    # 在檢查用原圖標出已排序四角，不修改最後成品。
    draw_points = np.rint(source_points).astype(np.int32).reshape(4,1,2)
    cv2.polylines(marked, [draw_points], True, (0,255,0), 3)
    for label, point in zip(["TL", "TR", "BR", "BL"], source_points):
        x, y = point
        cv2.putText(marked, label, (int(x)+8,int(y)-8),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0,0,255), 2)
    print("輸出寬、高：", output_width, output_height)

# 顯示原圖與分析用影像，成功才顯示校正成品。
cv2.imshow("Original", image)
cv2.imshow("Binary - detection only", binary)
cv2.imshow("Detected paper", marked)
if scanned is not None:
    cv2.imshow("Scanned color", scanned)
    cv2.imshow("Scanned gray", cv2.cvtColor(scanned, cv2.COLOR_BGR2GRAY))
cv2.waitKey(0)
cv2.destroyAllWindows()

# 這個課堂範例先只顯示，不自動覆寫檔案。
# 要示範存圖，可在確認成功後手動新增 imwrite()，使用新的輸出檔名。

```

### 輸出尺寸新增語法

`np.linalg.norm(tr-tl)` 是兩點差向量的長度，等同 `sqrt(dx²+dy²)`。
`np.ceil()` 向上取整；`int()` 轉成 OpenCV 尺寸需要的整數。此例把距離 99 當成包含兩端的 100 個像素位置。

### 預期與檢查

紙的四角是否完整？黑色小附點還在嗎？是否把其他白物體當成紙？標示文字是否跟著被存進成品？
找不到時只顯示分析圖，不應建立一張原圖副本就宣稱「校正成功」。
本課假設不符合時先換拍照方式，不追加一串學生不理解的濾鏡。

## 綜合實作｜觀察每一步的傾斜校正

### 引導思考

先灰階與平滑，再找邊緣和長線。沒有足夠且一致的線，就保留原灰階圖並提示；取得角度才產生旋轉候選。原圖仍保留，不能以「成功開視窗」當成校正正確。

這段是直寫式整合，尚未抽成自訂函式。角度估計與擴大畫布的內容就是前面兩個單元，放在一起觀察資料如何流動。

### 完整程式：`lesson07_deskew.py`

```python
import cv2

image = cv2.imread("test.jpg")
if image is None:
    raise FileNotFoundError("讀不到 test.jpg，請檢查檔名與工作目錄")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
import numpy as np

height, width = gray.shape
smooth = cv2.GaussianBlur(gray, (3, 3), 0)
edges = cv2.Canny(smooth, 50, 150, L2gradient=True)
lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=40,
                        minLineLength=max(30, width // 3), maxLineGap=10)
angles = []
rows = []
if lines is not None:
    for line in lines:
        x1, y1, x2, y2 = line[0]
        dx = float(x2 - x1)
        dy = float(y2 - y1)
        angle = np.degrees(np.arctan2(dy, dx))
        angle = (angle + 90) % 180 - 90
        if dx != 0 and abs(angle) <= 15:
            angles.append(float(angle))
            rows.append(float(y1) + (width / 2 - float(x1)) * dy / dx)

estimated = None
reason = "候選線段不足"
if len(angles) >= 4:
    values = np.array(angles)
    median = float(np.median(values))
    consistent = np.abs(values - median) <= 2
    positions = sorted(np.array(rows)[consistent].tolist())
    row_count = 0
    last_row = None
    for row in positions:
        if last_row is None or row - last_row > 4:
            row_count += 1
            last_row = row
    if consistent.mean() >= 0.75 and consistent.sum() >= 4 and row_count >= 3:
        estimated = float(np.median(values[consistent]))
        reason = "取得方向相近且分布於不同高度的長線"
    else:
        reason = "線段方向或高度分布不足"

corrected = gray.copy()
applied = 0.0
if estimated is not None and abs(estimated) >= 0.1:
    angle = estimated
    height, width = gray.shape
    center = ((width - 1) / 2, (height - 1) / 2)
    matrix = cv2.getRotationMatrix2D(center, angle, 1.0)
    cosine = abs(matrix[0, 0])
    sine = abs(matrix[0, 1])
    new_width = int(np.ceil(width * cosine + height * sine))
    new_height = int(np.ceil(height * cosine + width * sine))
    matrix[0, 2] += (new_width - 1) / 2 - center[0]
    matrix[1, 2] += (new_height - 1) / 2 - center[1]
    rotated = cv2.warpAffine(gray, matrix, (new_width, new_height),
                             flags=cv2.INTER_LINEAR,
                             borderMode=cv2.BORDER_CONSTANT, borderValue=255)
    corrected = rotated
    applied = angle

print("估計：", estimated)
print("實際旋轉：", applied)
print("原因：", reason)

cv2.imshow("Original", image)
cv2.imshow("Edges for estimation", edges)
cv2.imshow("Correction candidate", corrected)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 預期與檢查

原圖接近水平且線條清楚時，不應大幅旋轉。沒有可用線時，`estimated` 是 `None`，實際旋轉為 0，畫面保留原圖；這不代表已確認水平。

旋轉後仍需看五線是否更水平、頁框是否影響估計、附點是否保留。下一章整合成函式後，會再對候選圖估角，檢查殘餘角度，必要時拒絕採用。
