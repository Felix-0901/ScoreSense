# 第 7 章｜邊緣、傾斜偵測與旋轉校正

圖片中的線條可能歪斜，但要校正它，需要先分清楚三件事：哪些位置有明顯的亮度變化、這些變化形成什麼方向的線段，以及要旋轉多少才能回到水平。

本章從梯度與邊緣開始，接著學習輪廓、方向估計與幾何轉換。最後用已知角度的合成圖片檢查整個流程，再處理自己的照片。

## 學習目標

- 理解一階差分、Sobel、梯度方向與 Canny。
- 分辨邊緣圖、前景遮罩與輪廓。
- 正確轉換 NumPy 的列欄座標與 OpenCV 的 `(x,y)`。
- 比較最小外接矩形與霍夫線段的方向估計。
- 完成平移、固定角度旋轉、擴大畫布旋轉與透視轉換。
- 建立會報告無法估計原因的傾斜校正實驗。

## 範例準備

沿用 **Python 3.11** 與既有套件。先將以下程式存成 **`lesson07_common.py`**。各短範例另存成同資料夾中的 `.py`；共用檔不依賴前章程式。

素材是自行畫出的平行線與符號形狀，用來觀察方向，不是能直接當成音樂真值的完整樂譜。所有結果寫入新的 `output/lesson07` 子資料夾。

```python
from pathlib import Path
from tempfile import mkdtemp
import cv2
import numpy as np

BASE_DIR = Path(__file__).resolve().parent


def new_run(label):
    root = BASE_DIR / "output" / "lesson07"
    root.mkdir(parents=True, exist_ok=True)
    return Path(mkdtemp(prefix=f"{label}_", dir=str(root)))


def save_png(path, image):
    if image.dtype != np.uint8 or image.size == 0:
        raise ValueError("需要非空 uint8 影像")
    ok, buffer = cv2.imencode(".png", np.ascontiguousarray(image))
    if not ok:
        raise ValueError("PNG 編碼失敗")
    with Path(path).open("xb") as file:
        file.write(buffer.tobytes())


def make_score_demo():
    image = np.full((280, 640), 255, dtype=np.uint8)
    for top in [75, 175]:
        for row in range(5):
            y = top + row * 10
            cv2.line(image, (45, y), (595, y), 30, 1)
        for x, offset in [(120, 0), (240, 10), (360, 20), (480, 30)]:
            y = top + offset
            cv2.ellipse(image, (x, y), (7, 5), -20, 0, 360, 20, -1)
            cv2.line(image, (x + 6, y), (x + 6, y - 25), 20, 2)
    return image
```

## 單元一｜亮度變化與差分

同一區域的相鄰像素數值接近，通常沒有很強的亮度邊界；數值突然改變，就可能出現邊緣。

### 範例：一維亮度變化

```python
import numpy as np

row = np.array([20, 20, 20, 200, 200, 200, 20], dtype=np.uint8)
difference = np.diff(row.astype(np.int16))
print("原亮度：", row)
print("相鄰差：", difference)
```

結果包含 `+180` 與 `-180`，分別代表由暗到亮與由亮到暗。負值不是錯誤，它保存變化方向。

先轉型再相減，避免 `uint8` 回繞。雜訊也可能造成劇烈差分，所以「梯度大」不保證是物體真正邊界。

## 單元二｜Sobel 梯度

### 2-1｜水平與垂直方向

3 × 3 Sobel 的兩個核為：

```text
Gx：                 Gy：
-1  0  1             -1 -2 -1
-2  0  2              0  0  0
-1  0  1              1  2  1
```

`Gx` 測量沿 x 方向的亮度變化，因此對垂直邊界有明顯反應；`Gy` 測量沿 y 方向的變化，因此對水平邊界有明顯反應。

### 範例：手算一個位置

```python
import numpy as np

patch = np.array([[10, 10, 110], [10, 10, 110], [10, 10, 110]], dtype=np.float32)
kx = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], dtype=np.float32)
ky = kx.T
print("Gx：", float(np.sum(patch * kx)))
print("Gy：", float(np.sum(patch * ky)))
```

預期 `Gx=400`、`Gy=0`。結果可能超過 `255`，因此不能把梯度直接當成一般 8 位元圖片保存。

### 2-2｜保留正負號再產生顯示圖

### 範例：分別取得 x、y 梯度

```python
import cv2
import numpy as np
from lesson07_common import make_score_demo, new_run, save_png

run = new_run("sobel")
gray = make_score_demo()
gx = cv2.Sobel(gray, cv2.CV_32F, dx=1, dy=0, ksize=3)
gy = cv2.Sobel(gray, cv2.CV_32F, dx=0, dy=1, ksize=3)
# 除以 4 只用於這個 3 × 3 Sobel 的顯示，不修改原始梯度。
x_view = np.rint(np.abs(gx) / 4).clip(0, 255).astype(np.uint8)
y_view = np.rint(np.abs(gy) / 4).clip(0, 255).astype(np.uint8)
save_png(run / "gx.png", x_view)
save_png(run / "gy.png", y_view)
print("Gx 範圍：", float(gx.min()), float(gx.max()))
print("Gy 範圍：", float(gy.min()), float(gy.max()))
print(run)
```

`CV_32F` 保存浮點梯度。只有顯示用副本取絕對值；若先轉回 `uint8` 才計算方向，正負號已經遺失。

### 2-3｜梯度大小與方向

大小為 `sqrt(Gx²+Gy²)`，方向用 `atan2(Gy,Gx)`，它能處理不同象限與 `Gx=0`。梯度方向近似垂直於當地邊緣方向，不是沿著邊界走的方向。

### 範例：合併梯度

```python
import cv2
import numpy as np
from lesson07_common import make_score_demo, new_run, save_png

run = new_run("gradient")
gray = make_score_demo()
gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)
gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)
magnitude = np.hypot(gx, gy)
direction = np.degrees(np.arctan2(gy, gx))
view = cv2.normalize(magnitude, None, 0, 255, cv2.NORM_MINMAX).astype(np.uint8)
save_png(run / "magnitude.png", view)
print("有梯度的位置數：", np.count_nonzero(magnitude > 0))
print("方向形狀：", direction.shape)
print(run)
```

`normalize()` 是這張圖的顯示正規化，不適合拿不同圖片正規化後的亮度直接比較原始梯度強度。大小為零的位置沒有有意義的梯度方向。

## 單元三｜Canny 邊緣偵測

Canny 結合梯度、沿梯度方向保留局部極大值，以及雙門檻連通追蹤，產生較細的邊緣圖。強邊緣保留；弱邊緣需要沿符合條件的路徑連到強邊緣才保留。

本章先**明確呼叫高斯濾波**再呼叫 `cv2.Canny()`，不假設這個 API 已經替你完成想要的高斯前處理。

### 範例：雙門檻比較

```python
import cv2
from lesson07_common import make_score_demo, new_run, save_png

run = new_run("canny")
gray = make_score_demo()
smooth = cv2.GaussianBlur(gray, (3, 3), sigmaX=0)
for low, high in [(30, 90), (50, 150), (100, 200)]:
    edges = cv2.Canny(smooth, low, high, apertureSize=3, L2gradient=True)
    save_png(run / f"edges_{low}_{high}.png", edges)
print(run)
```

門檻作用在梯度強度，不是原始灰階值；不能直接套用「灰階超過 150 就是白色」的二值化解釋。門檻變高通常保留較強的邊緣，也可能漏掉細節。

`L2gradient=True` 使用歐氏梯度大小。Canny 的結果雖然只有黑白，但主要標記邊界，不是填滿的物體遮罩。

## 單元四｜輪廓與外接框

輪廓是前景邊界的一串座標。`findContours()` 通常由單通道二值圖尋找輪廓，白色是前景。`RETR_EXTERNAL` 只取外輪廓，不包含所有內部孔洞。

### 範例：找出兩個幾何形狀

```python
import cv2
import numpy as np
from lesson07_common import new_run, save_png

run = new_run("contours")
mask = np.zeros((180, 320), dtype=np.uint8)
cv2.rectangle(mask, (25, 35), (125, 115), 255, -1)
cv2.circle(mask, (235, 85), 35, 255, -1)
contours, hierarchy = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
marked = cv2.cvtColor(mask, cv2.COLOR_GRAY2BGR)
for contour in contours:
    x, y, w, h = cv2.boundingRect(contour)
    area = cv2.contourArea(contour)
    cv2.rectangle(marked, (x, y), (x + w - 1, y + h - 1), (0, 0, 255), 2)
    print("外接框：", (x, y, w, h), "輪廓面積：", area)
save_png(run / "mask.png", mask)
save_png(run / "boxes.png", marked)
print("外輪廓數：", len(contours))
print(run)
```

範例應找到兩個外輪廓，但輪廓的回傳順序不代表由左到右。`contourArea()` 算的是幾何面積，不保證等於白色像素數；兩者的邊界定義不同。

樂譜的五線與音符可能相接，找到一個輪廓不等於找到一個音符。這個方法是影像結構分析，不是完整符號辨識。

## 單元五｜前景座標與 `(x,y)` 順序

方向估計需要一組點。NumPy 的 `nonzero()` 或單參數 `where()` 對二維陣列回傳 **列 y、欄 x**；OpenCV 幾何函式需要 **x、y**。

### 範例：正確組成座標

```python
import numpy as np

mask = np.zeros((4, 6), dtype=np.uint8)
mask[1, 4] = 255
mask[2, 5] = 255
ys, xs = np.nonzero(mask)
points = np.column_stack((xs, ys)).astype(np.float32)
print("y：", ys)
print("x：", xs)
print("OpenCV 座標：\n", points)
```

結果應為 `[[4,1],[5,2]]`。`np.column_stack(np.where(mask > 0))` 會得到 `(y,x)`，不能不經轉換就把它當作幾何 `(x,y)`。

## 單元六｜最小外接旋轉矩形估計方向

`minAreaRect()` 找到包住全部點的最小面積旋轉矩形。這適合觀察一組前景的整體方向，但會被遠處雜點、標題、頁框與不規則排版影響。

本例不直接猜回傳角度的意義，而是用 `boxPoints()` 取得四個角，找出矩形長邊，再以 `atan2(dy,dx)` 算方向。這也避免把矩形寬邊、高邊的不同表示混在一起。

### 範例：以長邊估計傾斜

```python
import cv2
import numpy as np
from lesson07_common import make_score_demo


def estimate_rect(gray, max_angle=15.0):
    if gray.ndim != 2 or gray.dtype != np.uint8 or gray.size == 0:
        raise ValueError("需要非空 uint8 灰階圖")
    _, mask = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
    ys, xs = np.nonzero(mask)
    if len(xs) < 100:
        return None, "前景點不足"
    points = np.column_stack((xs, ys)).astype(np.float32)
    box = cv2.boxPoints(cv2.minAreaRect(points))
    vectors = np.roll(box, -1, axis=0) - box
    lengths = np.linalg.norm(vectors, axis=1)
    shortest = float(lengths.min())
    if shortest <= 0 or float(lengths.max()) / shortest < 1.5:
        return None, "外接矩形方向不明確"
    dx, dy = vectors[int(np.argmax(lengths))]
    angle = (float(np.degrees(np.arctan2(dy, dx))) + 90) % 180 - 90
    if abs(angle) > max_angle:
        return None, "方向超過輕微傾斜範圍"
    return angle, "以全體前景的長邊估計"


gray = make_score_demo()
angle, reason = estimate_rect(gray)
print("角度：", angle)
print("說明：", reason)
```

原始示範圖應接近 `0` 度。點數不足、外接矩形太接近正方形或方向超過 15 度時，回傳 `None`，表示沒有採用估計。

`0.0` 表示估計為水平，`None` 表示沒有足夠依據，兩者不能混用。門檻 `100` 點、長短邊比 `1.5` 與 `15` 度是本例的判斷條件，不是對所有照片都有效的定律。

### 思考實驗

在圖片角落加入一個黑點，再估一次。外接矩形涵蓋全部前景，一個遠處點可能改變包圍範圍；是否應該改用指定 ROI 或長線段方向？

## 單元七｜霍夫線段與方向一致性

### 7-1｜從邊緣找長線段

`HoughLinesP()` 回傳多條線段端點 `(x1,y1,x2,y2)`。`minLineLength` 限制線段長度，`maxLineGap` 允許小段缺口，`threshold` 是霍夫空間的投票門檻。

### 範例：畫出找到的線段

```python
import cv2
import numpy as np
from lesson07_common import make_score_demo, new_run, save_png

run = new_run("hough_lines")
gray = make_score_demo()
edges = cv2.Canny(cv2.GaussianBlur(gray, (3, 3), sigmaX=0), 50, 150, L2gradient=True)
lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=40,
                        minLineLength=200, maxLineGap=10)
marked = cv2.cvtColor(gray, cv2.COLOR_GRAY2BGR)
if lines is None:
    print("沒有找到符合條件的線段")
else:
    for x1, y1, x2, y2 in lines[:, 0, :]:
        cv2.line(marked, (int(x1), int(y1)), (int(x2), int(y2)), (0, 0, 255), 1)
    print("線段數：", len(lines))
save_png(run / "edges.png", edges)
save_png(run / "lines.png", marked)
print(run)
```

同一條有厚度的線可能產生兩側邊緣，也可能被分成多段，所以線段數不等於五線數。`None` 是沒有結果，不應直接走訪。

### 7-2｜用多條線段的方向取得候選角度

方向公式為 `atan2(y2-y1, x2-x1)`。將相差 180 度的方向合併到 `[-90,90)`，再挑選接近水平的長線段。

下面要求至少四段候選、大部分方向差不超過兩度，且分布在至少三組不同高度。這是減少誤判的規則，不是辨識機率，也不能證明線段一定是五線。

### 範例：估計並說明未採用的原因

```python
import cv2
import numpy as np
from lesson07_common import make_score_demo


def estimate_hough(gray, max_angle=15.0):
    if gray.ndim != 2 or gray.dtype != np.uint8 or gray.size == 0:
        raise ValueError("需要非空 uint8 灰階圖")
    h, w = gray.shape
    if min(h, w) < 32:
        return None, {"reason": "圖片太小", "segments": 0}
    smooth = cv2.GaussianBlur(gray, (3, 3), sigmaX=0)
    edges = cv2.Canny(smooth, 50, 150, L2gradient=True)
    lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=40,
                            minLineLength=max(30, round(w * 0.35)), maxLineGap=10)
    if lines is None:
        return None, {"reason": "找不到長線段", "segments": 0}
    angles, positions = [], []
    for x1, y1, x2, y2 in lines[:, 0, :]:
        dx, dy = float(x2 - x1), float(y2 - y1)
        angle = (float(np.degrees(np.arctan2(dy, dx))) + 90) % 180 - 90
        if dx == 0 or abs(angle) > max_angle:
            continue
        angles.append(angle)
        positions.append(float(y1) + ((w - 1) / 2 - float(x1)) * dy / dx)
    if len(angles) < 4:
        return None, {"reason": "候選長線段不足", "segments": len(angles)}
    values = np.array(angles)
    median = float(np.median(values))
    inliers = np.abs(values - median) <= 2.0
    ratio = float(inliers.mean())
    if ratio < 0.75 or np.count_nonzero(inliers) < 4:
        return None, {"reason": "線段方向不一致", "segments": len(angles)}
    rows = sorted(np.array(positions)[inliers].tolist())
    groups = 1
    anchor = rows[0]
    for row in rows[1:]:
        if row - anchor > 4.0:
            groups += 1
            anchor = row
    if groups < 3:
        return None, {"reason": "不同高度的線段不足", "segments": len(angles)}
    return float(np.median(values[inliers])), {
        "reason": "取得多條方向一致的長線段", "segments": len(angles),
        "inlier_ratio": ratio, "row_groups": groups,
    }


angle, detail = estimate_hough(make_score_demo())
print("角度：", angle)
print("紀錄：", detail)
```

同一線條的兩側在圖像中可能只隔幾個像素，範例用約 4 像素的高度分組，減少把重複邊緣當成獨立支持。圖片縮放後，這類以像素為單位的規則也需要重新評估。

若只有頁框、只有一條長線、線段方向互相矛盾，或影像轉了約 90 度，這個輕微傾斜估計器應拒絕或交由人工確認，不是強迫回傳一個角度。

## 單元八｜旋轉角度的正負方向

### 8-1｜影像座標與數學座標不同

影像的 y 軸向下，所以從左到右往下斜的線段有 `dy>0`，`atan2(dy,dx)` 會給正角度。

`getRotationMatrix2D()` 的正角度則表示畫面上**逆時針**旋轉。在本章這個定義下，將線段角度原樣傳入旋轉函式，就是把它轉回水平；不需要再憑直覺多加一次負號。

### 範例：由線段端點確認符號

```python
import numpy as np

x1, y1, x2, y2 = 10, 20, 110, 30
angle = float(np.degrees(np.arctan2(y2 - y1, x2 - x1)))
print("右側較低的線段角度：", angle)
print("本章校正使用的旋轉參數：", angle)
```

結果約為正 `5.71` 度。反過來，若用 OpenCV 的 `+7` 度先把水平圖逆時針旋轉，之後測到的線段角度應約為 `-7` 度。

不要只測一個方向。至少使用正、負與零角度三種情況驗證。

## 單元九｜幾何轉換的最小範例

### 9-1｜平移

仿射矩陣的最後一欄可以表達平移量。固定輸出畫布時，移出邊界的部分會被裁掉。

### 範例：向右與向下移動

```python
import cv2
import numpy as np
from lesson07_common import make_score_demo, new_run, save_png

run = new_run("translation")
gray = make_score_demo()
h, w = gray.shape
matrix = np.float32([[1, 0, 20], [0, 1, 15]])
shifted = cv2.warpAffine(gray, matrix, (w, h), borderValue=255)
save_png(run / "original.png", gray)
save_png(run / "shifted.png", shifted)
print(run)
```

### 9-2｜已知角度旋轉：固定畫布

先提供已知角度，只測試旋轉，不同時加入估角。`center` 是 `(x,y)`，輸出尺寸是 `(寬,高)`，白紙背景用 `255` 補邊。

### 範例：逆時針旋轉 7 度

```python
import cv2
from lesson07_common import make_score_demo, new_run, save_png

run = new_run("fixed_rotation")
gray = make_score_demo()
h, w = gray.shape
matrix = cv2.getRotationMatrix2D(((w - 1) / 2, (h - 1) / 2), 7.0, 1.0)
rotated = cv2.warpAffine(gray, matrix, (w, h), flags=cv2.INTER_LINEAR,
                         borderMode=cv2.BORDER_CONSTANT, borderValue=255)
save_png(run / "original.png", gray)
save_png(run / "rotated.png", rotated)
print(run)
```

固定畫布可能裁掉旋轉後的角落。白色補邊只決定空白位置的數值，不會增加畫布大小。

### 9-3｜擴大畫布再旋轉

旋轉後需要的寬高可以由原寬高與正弦、餘弦估算，再將旋轉中心移到新畫布中心。這能保留原畫布的範圍，但插值仍會改變像素。

### 範例：擴大輸出畫布

```python
import cv2
import numpy as np
from lesson07_common import make_score_demo, new_run, save_png


def rotate_expand(image, degrees):
    if image.dtype != np.uint8 or image.ndim not in (2, 3) or image.size == 0:
        raise ValueError("需要非空的 uint8 灰階圖或三通道圖")
    if image.ndim == 3 and image.shape[2] != 3:
        raise ValueError("彩圖需要三個通道")
    if not np.isfinite(degrees):
        raise ValueError("旋轉角度必須是有限數值")
    if abs(degrees) < 1e-9:
        return image.copy()
    h, w = image.shape[:2]
    center = ((w - 1) / 2.0, (h - 1) / 2.0)
    matrix = cv2.getRotationMatrix2D(center, float(degrees), 1.0)
    cosine, sine = abs(matrix[0, 0]), abs(matrix[0, 1])
    new_w = int(np.ceil(w * cosine + h * sine))
    new_h = int(np.ceil(h * cosine + w * sine))
    matrix[0, 2] += (new_w - 1) / 2.0 - center[0]
    matrix[1, 2] += (new_h - 1) / 2.0 - center[1]
    border = 255 if image.ndim == 2 else (255, 255, 255)
    return cv2.warpAffine(image, matrix, (new_w, new_h),
                          flags=cv2.INTER_LINEAR,
                          borderMode=cv2.BORDER_CONSTANT, borderValue=border)


run = new_run("expanded_rotation")
gray = make_score_demo()
rotated = rotate_expand(gray, 7.0)
save_png(run / "original.png", gray)
save_png(run / "rotated.png", rotated)
print("前後形狀：", gray.shape, rotated.shape)
print(run)
```

本例使用雙線性插值，因此灰階結果可能包含新的中間值。處理二值標籤時可考慮最近鄰；處理照片時通常先轉好幾何形狀，再重新二值化。

連續旋轉多次會重複插值；旋轉再轉回不保證像素完全相同。不要為了改善一點方向就反覆微調十幾次。

### 9-4｜90 度旋轉

若已經確定照片方向錯了 90 度，可使用像素重排，不必透過任意角度插值。但「判定應轉哪一邊」是另外一個問題。

### 範例：順時針旋轉 90 度

```python
import cv2
from lesson07_common import make_score_demo, new_run, save_png

run = new_run("quarter_turn")
gray = make_score_demo()
rotated = cv2.rotate(gray, cv2.ROTATE_90_CLOCKWISE)

```

### 9-5｜透視轉換

側面拍攝平面紙張時，可能形成梯形，單純旋轉不能把它拉回長方形。透視轉換使用四組對應點，四點順序必須一致。

### 範例：已知四角的平面校正

```python
import cv2
import numpy as np
from lesson07_common import new_run, save_png

run = new_run("perspective")
paper = np.full((180, 300), 245, dtype=np.uint8)
for y in [40, 65, 90, 115]:
    cv2.line(paper, (15, y), (284, y), 20, 2)
# 兩組點都是：左上、右上、右下、左下。
target = np.float32([[0, 0], [299, 0], [299, 179], [0, 179]])
source = np.float32([[80, 30], [340, 55], [360, 225], [30, 205]])
# 先由端正紙張產生一張已知透視變形的影像。
forward = cv2.getPerspectiveTransform(target, source)
image = cv2.warpPerspective(paper, forward, (400, 260),
                            flags=cv2.INTER_LINEAR, borderValue=70)
# 再用照片中的四個角點，映射回長方形。
matrix = cv2.getPerspectiveTransform(source, target)
rectified = cv2.warpPerspective(image, matrix, (300, 180),
                                flags=cv2.INTER_LINEAR, borderValue=255)
save_png(run / "original.png", image)
save_png(run / "rectified.png", rectified)
print(run)
```

這個範例先從端正紙張產生已知的透視變形，再映射回矩形；校正後的線段應接近水平，但兩次插值不會完全還原原始像素。範例已經知道四個角，不包含自動找紙張。真實照片還需要決定角點、輸出比例，以及是否有書頁彎曲；平面透視模型不能完整校正彎曲紙張。

## 綜合實作｜估角、旋轉與重新量測

### 一、先選定邊界

本實驗處理平面、接近水平、具有多條長線的圖片。超過輕微傾斜範圍、只有一條線、沒有足夠證據時，不自動旋轉。

先以最小外接矩形取得一個**比較值**，以多條霍夫線段的一致方向作為本次的旋轉依據。兩者不一致時，回看框線、標題與雜點，不任意取平均掩蓋差異。

```text
讀取灰階／建立已知 +7 度素材
    ↓
Sobel 與 Canny：保存診斷圖
    ↓
外接矩形估角 + 霍夫線段估角
    ↓
足夠且一致的長線段？
    ├─ 否 → 保留原圖，記錄原因
    └─ 是 → 擴大畫布並旋轉
                  ↓
             再次量測方向
                  ↓
         保存結果與需檢查事項
```

### 二、完整程式

存成 **`lesson07_deskew_lab.py`**。以下包含全部函式，不需要從前面的片段拼接。

```python
from pathlib import Path
from tempfile import mkdtemp
import json
import sys
import cv2
import numpy as np

BASE_DIR = Path(__file__).resolve().parent


def make_score_demo():
    image = np.full((280, 640), 255, dtype=np.uint8)
    for top in [75, 175]:
        for row in range(5):
            y = top + row * 10
            cv2.line(image, (45, y), (595, y), 30, 1)
        for x, offset in [(120, 0), (240, 10), (360, 20), (480, 30)]:
            y = top + offset
            cv2.ellipse(image, (x, y), (7, 5), -20, 0, 360, 20, -1)
            cv2.line(image, (x + 6, y), (x + 6, y - 25), 20, 2)
    return image


def rotate_expand(image, degrees):
    if image.dtype != np.uint8 or image.ndim not in (2, 3) or image.size == 0:
        raise ValueError("需要非空的 uint8 灰階圖或三通道圖")
    if image.ndim == 3 and image.shape[2] != 3:
        raise ValueError("彩圖需要三個通道")
    if not np.isfinite(degrees):
        raise ValueError("旋轉角度必須是有限數值")
    if abs(degrees) < 1e-9:
        return image.copy()
    h, w = image.shape[:2]
    center = ((w - 1) / 2.0, (h - 1) / 2.0)
    matrix = cv2.getRotationMatrix2D(center, float(degrees), 1.0)
    cosine, sine = abs(matrix[0, 0]), abs(matrix[0, 1])
    new_w = int(np.ceil(w * cosine + h * sine))
    new_h = int(np.ceil(h * cosine + w * sine))
    matrix[0, 2] += (new_w - 1) / 2.0 - center[0]
    matrix[1, 2] += (new_h - 1) / 2.0 - center[1]
    border = 255 if image.ndim == 2 else (255, 255, 255)
    return cv2.warpAffine(image, matrix, (new_w, new_h),
                          flags=cv2.INTER_LINEAR,
                          borderMode=cv2.BORDER_CONSTANT, borderValue=border)


def estimate_rect(gray, max_angle=15.0):
    if gray.ndim != 2 or gray.dtype != np.uint8 or gray.size == 0:
        raise ValueError("需要非空 uint8 灰階圖")
    _, mask = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
    ys, xs = np.nonzero(mask)
    if len(xs) < 100:
        return None, "前景點不足"
    points = np.column_stack((xs, ys)).astype(np.float32)
    box = cv2.boxPoints(cv2.minAreaRect(points))
    vectors = np.roll(box, -1, axis=0) - box
    lengths = np.linalg.norm(vectors, axis=1)
    shortest = float(lengths.min())
    if shortest <= 0 or float(lengths.max()) / shortest < 1.5:
        return None, "外接矩形方向不明確"
    dx, dy = vectors[int(np.argmax(lengths))]
    angle = (float(np.degrees(np.arctan2(dy, dx))) + 90) % 180 - 90
    if abs(angle) > max_angle:
        return None, "方向超過輕微傾斜範圍"
    return angle, "以全體前景的長邊估計"


def estimate_hough(gray, max_angle=15.0):
    if gray.ndim != 2 or gray.dtype != np.uint8 or gray.size == 0:
        raise ValueError("需要非空 uint8 灰階圖")
    h, w = gray.shape
    if min(h, w) < 32:
        return None, {"reason": "圖片太小", "segments": 0}
    smooth = cv2.GaussianBlur(gray, (3, 3), sigmaX=0)
    edges = cv2.Canny(smooth, 50, 150, L2gradient=True)
    lines = cv2.HoughLinesP(edges, 1, np.pi / 180, threshold=40,
                            minLineLength=max(30, round(w * 0.35)), maxLineGap=10)
    if lines is None:
        return None, {"reason": "找不到長線段", "segments": 0}
    angles, positions = [], []
    for x1, y1, x2, y2 in lines[:, 0, :]:
        dx, dy = float(x2 - x1), float(y2 - y1)
        angle = (float(np.degrees(np.arctan2(dy, dx))) + 90) % 180 - 90
        if dx == 0 or abs(angle) > max_angle:
            continue
        angles.append(angle)
        positions.append(float(y1) + ((w - 1) / 2 - float(x1)) * dy / dx)
    if len(angles) < 4:
        return None, {"reason": "候選長線段不足", "segments": len(angles)}
    values = np.array(angles)
    median = float(np.median(values))
    inliers = np.abs(values - median) <= 2.0
    ratio = float(inliers.mean())
    if ratio < 0.75 or np.count_nonzero(inliers) < 4:
        return None, {"reason": "線段方向不一致", "segments": len(angles)}
    rows = sorted(np.array(positions)[inliers].tolist())
    groups = 1
    anchor = rows[0]
    for row in rows[1:]:
        if row - anchor > 4.0:
            groups += 1
            anchor = row
    if groups < 3:
        return None, {"reason": "不同高度的線段不足", "segments": len(angles)}
    return float(np.median(values[inliers])), {
        "reason": "取得多條方向一致的長線段", "segments": len(angles),
        "inlier_ratio": ratio, "row_groups": groups,
    }


def read_gray(path):
    raw = Path(path).read_bytes()
    if not raw:
        raise ValueError("來源檔案是空的")
    image = cv2.imdecode(np.frombuffer(raw, dtype=np.uint8), cv2.IMREAD_COLOR)
    if image is None:
        raise ValueError("無法解碼圖片")
    return cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


def write_png(path, image):
    ok, buffer = cv2.imencode(".png", image)
    if not ok:
        raise ValueError("PNG 編碼失敗")
    with Path(path).open("xb") as file:
        file.write(buffer.tobytes())


def main():
    if len(sys.argv) > 1:
        source = Path(sys.argv[1]).expanduser().resolve()
        gray = read_gray(source)
        source_name = source.name
    else:
        gray = rotate_expand(make_score_demo(), 7.0)
        source_name = "generated_rotation_plus7"
    before = gray.copy()
    rect_angle, rect_reason = estimate_rect(gray)
    angle, detail = estimate_hough(gray)
    if angle is None:
        corrected = gray.copy()
        applied = 0.0
        status = "skipped_no_estimate"
    elif abs(angle) < 0.1:
        corrected = gray.copy()
        applied = 0.0
        status = "already_near_horizontal"
    else:
        corrected = rotate_expand(gray, angle)
        applied = angle
        status = "rotated"
    residual, residual_detail = estimate_hough(corrected)
    needs_review = angle is None or residual is None or abs(residual) > 1.0

    smooth = cv2.GaussianBlur(gray, (3, 3), sigmaX=0)
    edges = cv2.Canny(smooth, 50, 150, L2gradient=True)
    gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)
    gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)
    magnitude = cv2.normalize(np.hypot(gx, gy), None, 0, 255,
                              cv2.NORM_MINMAX).astype(np.uint8)
    root = BASE_DIR / "output" / "lesson07"
    root.mkdir(parents=True, exist_ok=True)
    run = Path(mkdtemp(prefix="deskew_", dir=str(root)))
    for name, image in {"original": gray, "edges": edges,
                        "gradient": magnitude, "corrected": corrected}.items():
        write_png(run / f"{name}.png", image)
    report = {
        "source": source_name,
        "original_shape": list(gray.shape),
        "corrected_shape": list(corrected.shape),
        "rect_angle": rect_angle,
        "rect_reason": rect_reason,
        "estimated_angle": angle,
        "applied_rotation": applied,
        "status": status,
        "estimation_detail": detail,
        "residual_angle": residual,
        "residual_detail": residual_detail,
        "needs_review": needs_review,
        "original_unchanged": bool(np.array_equal(before, gray)),
    }
    (run / "report.json").write_text(
        json.dumps(report, ensure_ascii=False, indent=2, allow_nan=False), encoding="utf-8")
    print(json.dumps(report, ensure_ascii=False, indent=2))
    print("輸出位置：", run)


if __name__ == "__main__":
    main()
```

### 三、驗證已知角度

執行 `python lesson07_deskew_lab.py`。示範先以 `+7` 度旋轉，估計值與校正參數應接近 `-7` 度；校正後殘餘角度應接近 `0`。容許少量差異，不要求霍夫結果每次都回傳相同小數。

再將素材產生角度依序改成 `-7、0、+12、-12`。檢查正負方向、原圖是否保留，以及輸出形狀是否合理。殘餘角度接近零只表示長線較水平，不代表沒有裁切、插值損失或符號錯誤。

### 四、驗證沒有足夠依據的情況

把 `gray` 換成全白圖、只含一條橫線的圖、主要是垂直線的圖。預期應記錄無法估計或不採用的原因，而不是把 `None` 寫成 `0` 後宣稱已經校正。

`needs_review=true` 表示需要檢查，不應當成自動通過。若重新量測失敗，也不能將它解讀成殘餘角度為零。

### 五、處理自己的圖片

執行 `python lesson07_deskew_lab.py "照片路徑.png"`。檢查 `edges.png`、`corrected.png` 與報告，記下哪條線可能不是想要的內容。

照片有梯形或彎曲時，先分辨問題類型。不要靠增加旋轉角度上限，讓原本只適合輕微傾斜的方法硬處理所有方向。

## 修改練習

1. 改變 Canny 門檻或最短線段長度，一次只改一個設定，記錄估計是否穩定。
2. 在角落加入雜點，比較外接矩形與長線段方法的敏感程度。
3. 為診斷圖畫出被採用的線段，不要把彩色標記送進估角或 OMR。
4. 用已知四個紙張角點做透視校正，再量測傾斜。說明為什麼這與只旋轉不是同一件事。
