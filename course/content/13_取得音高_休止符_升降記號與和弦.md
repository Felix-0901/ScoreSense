## 單元四｜完整版本

```python
def extract_pitch(note):
    if child(note, "rest") is not None:
        return None

    pitch = child(note, "pitch")
    if pitch is None:
        return None

    step_el = child(pitch, "step")
    alter_el = child(pitch, "alter")
    octave_el = child(pitch, "octave")

    if step_el is None or not (step_el.text or "").strip():
        return None

    step = (step_el.text or "").strip().upper()
    alter = float((alter_el.text or "0").strip()) if alter_el is not None else 0.0
    octave = int((octave_el.text or "0").strip()) if octave_el is not None else None

    return PitchInfo(step, alter, octave)
```

## 單元五｜把資料送進轉換器

```python
for note in iter_by_local_name(root, "note"):
    pitch = extract_pitch(note)

    if pitch is None:
        continue

    label = pitch_to_label(pitch, "solfege")
    print(pitch, "→", label)
```

到這裡已經能自動從 MusicXML 輸出：

```text
PitchInfo(step='C', alter=0, octave=4) → Do
PitchInfo(step='F', alter=1, octave=4) → Fa♯
```

## 單元六｜和弦怎麼知道？

MusicXML 中，和弦後續音可能含：

```xml
<chord/>
```

可以先記錄：

```python
is_chord_tone = child(note, "chord") is not None
```

這個 MVP 不做複雜和弦排版邏輯，但把資訊保留下來，未來可延伸。

## 單元七｜AnnotatedNote

我們希望最後報告除了 label 還保存原始資料：

```python
from dataclasses import dataclass, asdict


@dataclass
class AnnotatedNote:
    index: int
    step: str
    alter: float
    octave: int | None
    label: str
    is_chord_tone: bool

    def to_dict(self):
        return asdict(self)
```

這樣未來可輸出：

```json
{
  "index": 1,
  "step": "F",
  "alter": 1.0,
  "octave": 4,
  "label": "Fa♯",
  "is_chord_tone": false
}
```
