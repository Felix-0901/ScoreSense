## 單元一｜最適合先測 converter

`pitch_to_label()` 是純函式：

```text
相同輸入
↓
應該得到相同輸出
```

很適合測試。

```python
import unittest

from app.services.converter import PitchInfo, pitch_to_label


class ConverterTests(unittest.TestCase):
    def test_solfege(self):
        result = pitch_to_label(PitchInfo("C", 0, 4), "solfege")
        self.assertEqual(result, "Do")

    def test_sharp(self):
        result = pitch_to_label(PitchInfo("F", 1, 4), "solfege")
        self.assertEqual(result, "Fa♯")
```

## 單元二｜為什麼測試不是「看起來對」？

人工：

```text
我跑一下，好像是 Do。
```

測試：

```text
程式必須精確等於 "Do"，不然 fail。
```

尤其後面重構時，測試能防止改 A 壞 B。

## 單元三｜MusicXML 測試

建立一小段固定 XML，不依賴外部 OMR。

```python
SAMPLE = """<?xml version='1.0' encoding='UTF-8'?>
<score-partwise version='4.0'>
  <part-list>
    <score-part id='P1'><part-name>Music</part-name></score-part>
  </part-list>
  <part id='P1'>
    <measure number='1'>
      <note>
        <pitch><step>C</step><octave>4</octave></pitch>
        <duration>1</duration>
      </note>
    </measure>
  </part>
</score-partwise>
"""
```

用 `tempfile.TemporaryDirectory()` 建立暫存輸出，再檢查新 XML 是否含 `Do`。

## 單元五｜doctor.py

環境問題常見：

```text
cv2 沒裝
oemer 找不到
Python 版本不同
uvicorn 缺少
```

建立診斷腳本：

```python
import importlib
import shutil
import sys


def check_module(name):
    try:
        importlib.import_module(name)
        return True
    except Exception:
        return False


print("Python:", sys.version)

for name in ["cv2", "fastapi", "uvicorn", "multipart"]:
    print(name, check_module(name))

print("oemer:", shutil.which("oemer"))
```

## 單元六｜真正的除錯順序

如果圖片處理失敗：

```text
1. 輸入檔存在嗎？
2. OpenCV 讀得到嗎？
3. 前處理輸出有嗎？
4. oemer command 存在嗎？
5. oemer.log 說什麼？
6. 有 MusicXML 嗎？
7. MusicXML 有 note 嗎？
8. parser 有讀出 PitchInfo 嗎？
9. converter 是否正確？
10. output MusicXML 是否寫出？
```

不要看到最終沒結果就從所有檔案一起亂改。

## 挑戰｜故意破壞專案

分組做：

1. 把 `BASE_LABELS` 的 C 改錯。
2. 把 input path 改錯。
3. 把 oemer command 改成不存在。
4. 把 XML 的 step 刪掉。

另一位學生只能看錯誤與 log 找原因。

這是非常有效的除錯練習。
