前面我們完成「圖片」這一側。接下來先把圖片放一邊，開始研究另一個問題：**如果電腦已經知道某顆音是 C4、F♯4，它要怎麼保存？**

- 使用 dataclass 建立 `PitchInfo`。

## 單元一｜不要把 `F#4` 當成不能拆的字串

人看到：

```text
F#4
```

可以理解：

```text
音名：F
升降：升半音
八度：4
```

程式也可以分開保存：

```python
step = "F"
alter = 1
octave = 4
```

這樣比永遠靠字串切割可靠。

---

## 單元二｜alter 為什麼是數字？

MusicXML 常使用：

```text
alter = 0   → 原音
alter = 1   → 升半音
alter = -1  → 降半音
alter = 2   → 重升
alter = -2  → 重降
```

某些情況也可能有：

```text
0.5
-0.5
```

因此 MVP 使用 `float`。

## 單元三｜建立 PitchInfo

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class PitchInfo:
    step: str
    alter: float = 0
    octave: int | None = None
```

建立資料：

```python
c4 = PitchInfo("C", 0, 4)
f_sharp_4 = PitchInfo("F", 1, 4)

print(c4)
print(f_sharp_4.step)
```

### `frozen=True` 是什麼？

表示建立後不希望隨意修改。

音高資料在轉換過程中應該被「讀取」，而不是某個函式偷偷把原始音高改掉。

---

## 單元四｜休止符不是音高

休止符沒有：

```text
step
alter
octave
```

因此未來 `_extract_pitch()` 遇到休止符時，不會硬造一個假音高，而是回傳：

```python
None
```

這是很重要的資料建模觀念：

> 沒有資料時，不要用錯誤資料假裝存在。

---

## 單元五｜一串音符

```python
notes = [
    PitchInfo("C", 0, 4),
    PitchInfo("D", 0, 4),
    PitchInfo("F", 1, 4),
]

for pitch in notes:
    print(pitch.step, pitch.alter, pitch.octave)
```

後面從 MusicXML 解析後，會得到很類似的資料。

## 綜合練習｜把文字拆成 PitchInfo

先只支援：

```text
C4
D4
F#4
Bb3
```

可以先寫簡化版：

```python
def parse_pitch_text(text):
    text = text.strip()
    step = text[0].upper()
    octave = int(text[-1])

    middle = text[1:-1]
    if middle == "#":
        alter = 1
    elif middle == "b":
        alter = -1
    else:
        alter = 0

    return PitchInfo(step, alter, octave)
```

測試：

```python
print(parse_pitch_text("F#4"))
print(parse_pitch_text("Bb3"))
```

這個 parser 不是最終專案必需功能，但它能幫助學生真正理解資料如何拆解。
