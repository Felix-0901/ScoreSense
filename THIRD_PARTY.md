# Third-party components

This project does not vendor third-party source code. Dependencies are installed into your Python environment.

- FastAPI — web API framework.
- Uvicorn — ASGI server.
- OpenCV — image preprocessing.
- NumPy — numerical arrays used by OpenCV and compatibility pinning.
- oemer 0.1.8 — optional Optical Music Recognition backend; MIT License.
- OpenSheetMusicDisplay — loaded by the demo web UI from jsDelivr CDN to render MusicXML in the browser.

The project's own note conversion, MusicXML annotation, pipeline integration, API and UI code are under this project folder.
